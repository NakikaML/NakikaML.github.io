## 样本空间与随机事件

#### 随机试验

**试验**是对实验和观察的统称，并不限于物理实验：抛一次骰子是试验，观察明天的天气、观察出门是否堵车同样是试验。

在概率论中，将具有以下特点的试验称为**随机试验**：

1. 可以在相同的条件下**重复**地进行；
2. 每次试验的可能结果**不只一个**，并且事先能明确试验的**所有可能结果**；
3. 进行一次试验之前**不能确定**哪一个结果会出现。

随机试验简称**试验**，记作 $E$；只满足第 (2)(3) 两条的现象称为**随机现象**。

概率论与数理统计的研究对象是**随机现象**，主要研究对象是**大量重复的随机试验**。

#### 样本点与样本空间

试验 $E$ 的每个不可再分的可能结果称为**样本点**，记作 $\omega$。样本点是试验结果的最基本元素，本身不再分解。

试验 $E$ 的所有可能结果，即**全体样本点组成的集合**，称为**样本空间**，记作 $\Omega$。

> **例**：$E$：掷一枚骰子，出现的点数，则 $\Omega = \{1,2,3,4,5,6\}$。

每次试验**有且只有一个**含在样本空间中的结果发生。

> **注意**：样本空间至少要有**两个**样本点，只有一个结果就不是随机试验。

按样本点的多少，样本空间分两类：
- 样本点为**有限个或可数个**的样本空间，称为**离散样本空间**；
- 样本点为**不可列无限个**的样本空间，称为**连续样本空间**。

#### 随机事件

试验 $E$ 的结果称为**随机事件**（简称**事件**），它是样本空间 $\Omega$ 的一个**子集**，常记作 $A, B, C$ 等。在每次试验中，事件有且仅有一个样本点出现，就称该事件**发生**。

> 这里的"结果"要理解成一句**陈述句**——"掷出偶数点"是事件，而"掷出的是偶数点吗？""真希望掷出偶数点！"都不是：只有陈述句才有确定的真假（发生 / 不发生）。

特别地，可以将事件分类为：

（1）基本事件：由**一个样本点**组成的单点集，称为**基本事件**。

> **注意**：基本事件是**两两互不相容**的——单点集之间不可能有公共样本点。

（2）不可能事件：空集 $\varnothing$ 不包含任何样本点，它也是样本空间的子集，在每次试验中都不发生，称为**不可能事件**。

> **注意**："骰子投出 7"是不可能事件，但要注意 $A = \varnothing$，**而不是** $A = \{7\}$——因为 $\{7\} \not\subset \Omega$，它根本不是一个（合法的）事件。

（3）必然事件：样本空间 $\Omega$ 包含所有的样本点，它是 $\Omega$ 自身的子集，在每次试验中总是发生，称为**必然事件**。

## 事件的关系和运算

### 事件的关系

#### 事件关系的概念

**事件是一个集合**，因而事件间的关系与运算按集合来处理。设试验 $E$ 的样本空间为 $\Omega$，本节讨论的 $A, B, A_k\ (k = 1, 2, \cdots)$ 都是 $\Omega$ 的子集。

> **记号约定**：本课 $A \subset B$ 与 $A \subseteq B$ 同义，只表示"$A$ 含于 $B$"，不区分真包含。

#### 包含关系

若 $A \subset B$，称事件 $A$ **包含于**事件 $B$（即 $A$ 的样本点都在 $B$ 中），表示"$A$ 发生必导致 $B$ 发生"。

![A 包含于 B：A 的样本点都在 B 中](/notes-assets/ptms1-01-subset-of-b.jpg)

#### 相等关系

若 $A \subset B$ 且 $B \subset A$，记为 $A = B$，称事件 $A$ 和 $B$ **相等**，表示"如果 $A$ 发生，则 $B$ 必然发生"或"如果 $B$ 发生，则 $A$ 必然发生"。相等的事件含有**相同的样本点**。

#### 互斥关系（互不相容）

若 $AB = \varnothing$，称事件 $A$ 与 $B$ **互不相容**（或**互斥**），表示"事件 $A$ 与事件 $B$ 不能同时发生"。

#### 互逆关系（对立事件）

若 $A \cup B = \Omega$ 且 $AB = \varnothing$，则称事件 $A$ 与 $B$ **互逆**（**对立事件**）。对每次试验而言，$A$ 与 $B$ 中必有一个发生、且仅有一个发生。事件 $A$ 的对立事件记作 $\bar A$，且 $\bar{\bar A} = A$。

![互斥事件与对立事件](/notes-assets/ptms1-02-mutex-vs-complement.jpg)

| 对比维度 | 互斥 | 对立 |
| :--- | :--- | :--- |
| **定义式** | $AB = \varnothing$ | $AB = \varnothing$ 且 $A \cup B = \Omega$ |
| **能否同时发生** | 不能 | 不能 |
| **是否必有一个发生** | 不一定 | 一定 |
| **两者关系** | 对立的必要条件 | 对立 = 互斥 + 完备 |

> **例**：掷骰子时 $A = \{1\}$ 与 $B = \{2\}$ 互斥但**不对立**（还可能掷出 3）；$A = \{1\}$ 与 $B = \{2,3,4,5,6\}$ 才构成对立。

### 事件的运算

#### 和事件（事件的并）

$$
A \cup B = \{\omega : \omega \in A \text{ 或 } \omega \in B\}
$$

称为事件 $A$ 与 $B$ 的**和事件**，也记作 $A + B$，表示"$A$ 或 $B$ 至少有一个发生"。类似地，
$$
\bigcup_{k=1}^{n} A_k = A_1 \cup A_2 \cup \cdots \cup A_n, \qquad \bigcup_{k=1}^{\infty} A_k = A_1 \cup A_2 \cup \cdots
$$

分别称为 $n$ 个事件、可列个事件的和事件。

#### 积事件（事件的交）

$$
A \cap B = \{\omega : \omega \in A \text{ 且 } \omega \in B\}
$$

称为事件 $A$ 与 $B$ 的**积事件**，常简记作 $AB$，表示"$A$ 和 $B$ 同时发生"。同样有 $\bigcap\limits_{k=1}^{n} A_k$、$\bigcap\limits_{k=1}^{\infty} A_k$ 的记法。

#### 差事件

$$
A - B = \{\omega : \omega \in A \text{ 且 } \omega \notin B\} = A\bar B
$$

称为事件 $A$ 与 $B$ 的**差事件**，表示"$A$ 发生且 $B$ 不发生"。

![事件的运算：并、交、差](/notes-assets/ptms1-03-set-operations.jpg)

由上述三种运算可以推出下列结论：
$$
\bar \Omega = \varnothing, \qquad \bar \varnothing = \Omega, \qquad \bar{\bar A} = A
$$
$$
\Omega \cup A = \Omega, \qquad \varnothing \cup A = A, \qquad \Omega \cap A = A, \qquad \varnothing \cap A = \varnothing
$$
$$
AB = \varnothing \iff A \subset \bar B, \qquad A \subset B \iff A\bar B = \varnothing
$$

| 名称 | 记法 | 集合含义 | 语言表述 |
| :--- | :--- | :--- | :--- |
| **包含** | $A \subset B$ | $A$ 的每个样本点都在 $B$ 中 | $A$ 发生必然导致 $B$ 发生 |
| **相等** | $A = B$ | 两集合完全相同 | $A$、$B$ 互相蕴含 |
| **互斥** | $A \cap B = \varnothing$ | 无公共样本点 | 不能同时发生 |
| **对立** | $B = \bar A$ | 互补且 $A \cup B = \Omega$ | 必有一个发生、且不同时发生 |
| **并** | $A \cup B = A + B$ | 两集合之并 | $A$、$B$ 至少发生一个 |
| **交** | $A \cap B = AB$ | 两集合之交 | $A$、$B$ 同时发生 |
| **差** | $A - B = A\bar B$ | 在 $A$ 中但不在 $B$ 中 | $A$ 发生且 $B$ 不发生 |

### 事件的运算律

#### 交换律、结合律、分配律

| 运算律 | 内容 |
| :--- | :--- |
| **交换律** | $A \cup B = B \cup A$，$A \cap B = B \cap A$ |
| **结合律** | $A \cup (B \cup C) = (A \cup B) \cup C$，$A \cap (B \cap C) = (A \cap B) \cap C$ |
| **分配律** | $(A \cup B) \cap C = (A \cap C) \cup (B \cap C)$，$(A \cap B) \cup C = (A \cup C) \cap (B \cup C)$ |

#### 吸收律

若 $A \subset B$，则 $A \cap B = A$，$A \cup B = B$。

#### 对偶律（德·摩根律）

$$
\overline{A \cup B} = \bar A \cap \bar B, \qquad \overline{A \cap B} = \bar A \cup \bar B
$$

推广到可列个事件：
$$
\overline{\bigcup_{k} A_k} = \bigcap_{k} \bar A_k, \qquad \overline{\bigcap_{k} A_k} = \bigcup_{k} \bar A_k
$$

注意：事件运算中"加括号""去括号"的运算律**一般不成立**：
$$
A - (B - C) \neq (A - B) + C
$$

左边 $= A\overline{(B\bar C)} = A(\bar B \cup C) = A\bar B \cup AC$，右边 $= A\bar B \cup C$，两者一般不等。

> **注意**：遇到差事件一律先化成"交补"（$A - B = A\bar B$）再动，唯一靠得住的是分配律与对偶律。

:::example 例 1 · 用事件运算表示复杂事件
**题目**： 已知一批灯泡中包含有多件次品，随机抽取三个并检验。设事件 $A, B, C$ 分别表示"第一、二、三次所抽到的灯泡是正品"，试用 $A, B, C$ 及其运算表示下列事件：(1) 第三次抽到正品；(2) 只有第三次抽到正品；(3) 恰有一次抽到次品；(4) 至多抽到一件次品。

**思路**： 三种句式各有一套翻译法——"只有某一次"= 该次发生且**其余全不发生**；"恰有一次"= 把每一种位置**枚举**出来再并；"至多一件"= 枚举"0 件"与"1 件"两种情形。

**解**：

(1) $C$

(2) $\bar A \bar B C$

(3) 恰有一次抽到次品，即恰有两次正品：
$$
\bar A B C \cup A \bar B C \cup A B \bar C
$$
(4) 至多一件次品，即至少两件正品（三正品 + 恰两正品）：
$$
ABC \cup \bar A B C \cup A \bar B C \cup A B \bar C
$$

**评注**： 三个易错点：① "只有"必须把其余事件取补，漏一个就变成"至少"；② "恰有"靠枚举，元素少时直接列全，别用容斥想复杂了；③ **注意 $A, B, C$ 表示的是"正品"**，所以"恰有一次次品"对应的是"恰有两个不戴横线"——先数清题目定义的到底是哪个方向，再动笔。
:::

:::example 例 2 · 化简事件式
**题目**： 设 $A, B$ 是两个随机事件，化简 $(A \cup B)(A \cup \bar B)(\bar A \cup B)$。

**思路**： 前两个因子形式对称，先用分配律合并成 $(A \cup B\bar B)$，再用 $B\bar B = \varnothing$、$A \cup \varnothing = A$ 收成单项。

**解**：
$$
(A \cup B)(A \cup \bar B)(\bar A \cup B) = (A \cup B\bar B)(\bar A \cup B) = A(\bar A \cup B) = A\bar A \cup AB = AB
$$

**评注**： 化简题的顺序永远是"**先并两项、再乘第三项**"：乘法（交）对加法（并）分配，反向也能用来把两项合并。看到 $(A \cup B)(A \cup \bar B)$ 这种"只差一个补"的结构，直接用分配律收成一个字母。
:::

:::example 例 3 · 对立事件的文字翻译
**题目**： 以 $A$ 表示事件"甲产品畅销，乙产品滞销"，则其对立事件 $\bar A$ 为（　　）

A. 甲产品滞销，乙产品滞销　　B. 甲、乙两种产品均畅销

C. 甲产品滞销　　　　　　　　D. 甲产品滞销或乙产品畅销

**思路**： 先把 $A$ 写成"两个事件的交"，再对整个式子取补。

**解**： 设 $B$ = "甲产品畅销"，$C$ = "乙产品畅销"，则 $A = B\bar C$，故
$$
\bar A = \overline{B\bar C} = \bar B \cup C
$$
即"甲产品滞销或乙产品畅销"，选 **D**。

**评注**： 文字型选择题的统一做法是**先翻译成符号、再取补**。"且"取补变"或"、"畅销"取补变"滞销"，一步对偶律就能完成；靠语感硬读，十有八九会选成 C。
:::

## 古典概型

#### 概率的直观含义

对随机事件 $A$ 发生可能性大小的**度量**，称为事件 $A$ 的**概率**，记作 $P(A)$。

#### 古典概型的概念

称具有以下两个特点的试验为**古典概型**（**等可能概型**）：

1. **有限性**：试验 $E$ 的样本空间 $\Omega$ 只包含有限个样本点，即 $\Omega = \{\omega_1, \omega_2, \cdots, \omega_n\}$；
2. **等可能性**：每个样本点出现的可能性相同。

若事件 $A$ 由 $k$ 个基本事件组成（$k$ 称为**有利于 $A$ 的样本点数**），则有

$$
P(A) = \frac{k}{n} = \frac{A \text{ 包含的基本事件数}}{\Omega \text{ 中的基本事件总数}}
$$

#### 计数原理

古典概型的全部计算都落在"数样本点"上（组合数学计数原理的系统展开见离散数学）：

| 计数对象 | 公式 | 备注 |
| :--- | :--- | :--- |
| 乘法原理 | $m_1 m_2 \cdots m_r$ | 分步完成 |
| 加法原理 | $m_1 + m_2 + \cdots + m_r$ | 分类完成，各类互斥 |
| 排列（不放回、取 $m$ 个排） | $A_n^m = n(n-1)\cdots(n-m+1) = \dfrac{n!}{(n-m)!}$ | 与顺序有关 |
| 全排列 | $A_n^n = n!$ | 排列的特例 $m = n$ |
| 组合（不放回、取 $m$ 个） | $C_n^m = \dfrac{A_n^m}{m!} = \dfrac{n!}{m!\,(n-m)!}$ | 与顺序无关 |
| 可重复排列 | $n^m$ | 有放回，$m$ 个位置各有 $n$ 种选法 |

由定义立即可得组合数的三条常用性质：

$$
①\ C_n^m = C_n^{n-m}, \qquad ②\ C_{n+1}^m = C_n^m + C_n^{m-1}, \qquad ③\ C_{n+k+1}^{k} = \sum_{i=0}^{k} C_{n+i}^{i}
$$

:::example 例 1 · 置球入盒模型
**题目**： 将 $n$ 只球随机地放入 $N\ (n \le N)$ 个盒子中，设每个盒子都可以容纳 $n$ 只球，求：(1) 每个盒子最多只有一只球的概率 $P_1$；(2) 恰有 $m\ (m \le n)$ 只球放入某一个指定的盒子中的概率 $P_2$；(3) $n$ 只球全部放入某一个盒子中的概率 $P_3$。

**思路**： 先把样本点总数定死：**每只球都有 $N$ 种选择**，$n$ 只球共 $N^n$ 种（这是"可分辨的球 × 有放回"的标准口径）。然后逐问数"有利情形"：(1) 先挑盒子再排球；(2) 先选球再放剩余；(3) 只需挑盒子。

**解**：

(1) 先从 $N$ 个盒子中选出 $n$ 个（$C_N^n$），再把 $n$ 只球在这 $n$ 个盒子中排列（$n! = A_n^n$）：
$$
P_1 = \frac{C_N^n \cdot A_n^n}{N^n} = \frac{A_N^n}{N^n}
$$
(2) 从 $n$ 只球中选 $m$ 只放进指定盒子（$C_n^m$），其余 $n-m$ 只每只都有 $N-1$ 个盒子可选：
$$
P_2 = \frac{C_n^m \cdot (N-1)^{n-m}}{N^n}
$$
(3) 只需选出那一个盒子（$C_N^1 = N$），球全放进去只有一种放法：
$$
P_3 = \frac{C_N^1}{N^n} = \frac{1}{N^{n-1}}
$$

**评注**： 置球入盒是古典概型的"标准件"——**球可分辨、盒不空限制**，总数永远是 $N^n$。第 (2) 问的分母不要跟着写成 $(N-1)^{n}$ 之类；第 (3) 问的结果 $1/N^{n-1}$ 恰好说明"球越多、越不可能全挤进一个盒子"，可作为检验。
:::

:::example 例 2 · 生日问题 · 正难则反
**题目**： 设某班有 60 人，求至少 2 人生日在同一天的概率（近似认为每年有 365 天）。

**思路**： 正面要分"恰有 2 人同日""恰有 3 人同日"……，几乎无从下手；反面"所有人生日都不同"只有一种结构，且是排列问题。

**解**： 60 人的生日共有 $365^{60}$ 种等可能情形。$\bar A$ = "60 人生日全不相同"，相当于从 365 天中取 60 天再分给 60 人：
$$
P(\bar A) = \frac{C_{365}^{60} \cdot 60!}{365^{60}} = \frac{A_{365}^{60}}{365^{60}}, \qquad P(A) = 1 - \frac{A_{365}^{60}}{365^{60}}
$$
（该值约 $0.994$，即"几乎必有同生日"，这就是所谓的生日悖论。）

**评注**： ① "至少"一律先想对立面，$1 - P(\bar A)$ 往往一步到位；② 注意 $C_{365}^{60}\cdot 60! = A_{365}^{60}$，写成哪个都行，写成排列更便于和"每人不同生日"这句话对上；③ 这类"球放入盒、盒不能重复"的模型与例1 是同一套：60 个"球"放进 365 个"盒子"，要求每盒至多一球。
:::

:::example 例 3 · 分班问题 · 分组计数
**题目**： 15 名新生中有 3 名竞赛生，随机将 15 名新生平均分配到 3 个班级中去，求：(1) 每个班级各分配到一名竞赛生的概率；(2) 3 名竞赛生分配到同一班级的概率。

**思路**： 总情形是"15 人分成 3 组、每组 5 人"，分母为 $C_{15}^{5}C_{10}^{5}C_{5}^{5}$（组是有区别的班级，不必再乘 $3!$）。分子按竞赛生的分布分情形数。

**解**： (1) 3 名竞赛生一人一班（$A_3^3$ 种分法），其余 12 人补齐每班 4 个空位：
$$
P(A) = \frac{A_3^3 \cdot C_{12}^{4} C_8^4 C_4^4}{C_{15}^{5} C_{10}^{5} C_5^5} = \frac{25}{91}
$$
(2) 3 名竞赛生同班：先选班级（$C_3^1$），该班再补 2 人（$C_{12}^2$），其余两班分掉剩下 10 人：
$$
P(B) = \frac{C_3^1 \cdot C_{12}^2 C_{10}^5 C_5^5}{C_{15}^5 C_{10}^5 C_5^5} = \frac{6}{91}
$$

**评注**： ① 题目说"**平均分配**"，分母就是三个组合数相乘，**不要**再乘 $3!$ ——班级本身有区别，把 15 人分成"甲班 5、乙班 5、丙班 5"已经自带顺序；② 分子同样是"先安排特殊元素（竞赛生）、再补齐"；③ 两个答案分母相同，可约分后再算，能省掉大量手算。
:::

:::example 例 4 · 重复字母的排列
**题目**： 将 C, C, E, E, I, N, S 这 7 个字母随机地排成一行，求恰好排成 "SCIENCE" 的概率。

**思路**： 分子只有 1 种（就是 SCIENCE 这一个词），关键是分母——7 个位置里有重复字母，必须**去重**。

**解**： 把两个 C、两个 E 各自视为可分辨，则 7 个字母共有 $7!$ 种排法；而排出 "SCIENCE" 时两个 C 可互换、两个 E 可互换，共 $2! \cdot 2!$ 种：
$$
P = \frac{2! \cdot 2!}{7!} = \frac{4}{5040} = \frac{1}{1260}
$$
（等价写法：总排法 $\dfrac{7!}{2!\,2!} = 1260$，有利情形 $1$ 种。）

**评注**： 含重复字母的排列，分母要除以各重复字母的阶乘；分子若也含重复字母，要用同样的"标记法"补回，**分子分母的口径必须一致**。本题答案与课堂记录的 $A_2^2 A_2^2/7!$ 是同一个数。
:::

:::example 例 5 · 有放回 vs 不放回抽样
**题目**： 一批数量为 100 的同型号产品中有 30 件次品。按两种方式抽取 2 件：（a）**有放回**，（b）**不放回**。分别求：(1) 两件都是次品的概率；(2) 第 1 件是次品、第 2 件是正品的概率。

**思路**： 关键差别只有一句：**第二次抽取时面对的总体是否改变**。有放回时仍是"100 件、30 件次品"，两次独立，总数 $100^2$；不放回时第二次面对"99 件"，总数 $100 \times 99$。

**解**： （a）有放回，$n = 100 \times 100 = 10000$。

(1) $k = 30 \times 30 = 900$，$P = \dfrac{900}{10000} = 0.09$；(2) $k = 30 \times 70 = 2100$，$P = \dfrac{2100}{10000} = 0.21$。

（b）不放回，$n = 100 \times 99 = 9900$。

(1) $k = 30 \times 29 = 870$，$P = \dfrac{870}{9900} = \dfrac{29}{330} \approx 0.088$；(2) $k = 30 \times 70 = 2100$，$P = \dfrac{2100}{9900} = \dfrac{7}{33} \approx 0.212$。

**评注**： ① 第 (2) 问把"第 1 件正品、第 2 件次品"也算一遍，概率同样是 $\frac{7}{33}$——**先后次序不影响结果**，与例7 是同一件事；② 也可以写成 $\frac{30}{100} \times \frac{70}{99}$，即"第一次取到次品的比例 × 第二次在剩余品中取到正品的比例"，这种"分数相乘"正是 §2.1 条件概率的雏形；③ 两种抽法只差一点点（$0.09$ 与 $0.088$），说明**总体很大时，不放回近似等于有放回**。
:::

:::example 例 6 · 抽奖券问题 · 公平性
**题目**： 某超市有奖销售，投放 $n$ 张奖券只有 1 张有奖，每位顾客可抽 1 张。求第 $k$ 位顾客中奖的概率（$1 \le k \le n$）。

**思路**： 把"抽奖"看成"给 $n$ 位顾客随机分配 $n$ 张奖券的一个排列"，总数 $n!$；再数"有奖那张恰好落在第 $k$ 位顾客手中"的排列数。

**解**： 总数 $n!$；有利情形：第 $k$ 位拿定那张有奖券（1 种），其余 $n-1$ 张任意分配（$(n-1)!$ 种），故
$$
P = \frac{(n-1)!}{n!} = \frac{1}{n}
$$

**评注**： ① 结果**与 $k$ 无关**——先抽后抽一样公平，**公平性来自对称性，而不是来自顺序**；② 也可以一句话秒杀：$n$ 张券对 $n$ 个人完全对称，有奖券落在谁手里各占 $\frac{1}{n}$；③ 若奖券有 $m$ 张有奖，同样推法得 $P = \frac{m}{n}$。
:::

## 几何概型

#### 定义

试验 $E$ 的样本空间 $\Omega$ 充满某个区域（线段，或平面、空间中的有界区域）。随机地向 $\Omega$ 投掷一点 $M$，若点 $M$ 落在 $\Omega$ 内**度量相同**的子空间（或子区域）的可能性相等，则称这种随机试验为**几何概型**。

也可表述为：点 $M$ 落在 $\Omega$ 内任意子空间（或子区域）$G$ 的概率，**只与 $G$ 的度量（长度、面积、体积）成正比，而与 $G$ 的位置和形状无关**。

> 几何概型把**等可能事件的概念从有限延伸到了无限**。

#### 计算公式

设事件 $A$ 表示点 $M$ 落在 $G$ 内，则

$$
P(A) = \frac{m(G)}{m(\Omega)}
$$

其中 $m(G)$、$m(\Omega)$ 分别是 $G$ 与 $\Omega$ 的度量（$G$ 为区间取长度、为平面区域取面积、为空间区域取体积）。

> **注意**：单个点的度量恒为 $0$，故 $P(\{\omega\}) = 0$——这正兑现了 §1.1 的提醒"概率为 $0$ 的事件不一定是不可能事件"。也因此，**开区间与闭区间在概率计算中毫无差别**。

#### 与古典概型的对照

| 对比维度 | 古典概型 | 几何概型 |
| :--- | :--- | :--- |
| **样本点个数** | 有限个 | 无限个（连续） |
| **"等可能"的含义** | 每个样本点出现的机会相同 | 随机点落在区域内任意位置的机会相同 |
| **概率的计算** | 数个数之比 $k/n$ | 度量之比 $m(G)/m(\Omega)$ |
| **技术工具** | 排列组合 | 长度 / 面积 / 体积 |
| **单个样本点的概率** | $\dfrac{1}{n} > 0$ | $0$ |
| **典型场景** | 抽球、抽签、电话号码 | 等车时间、射击落点、随机取数 |

:::example 例 1 · 一维几何概型 · 等车时间
**题目**： 某公共汽车从上午 7:00 起每隔 15 min 来一趟。一乘客在 7:00 到 7:30 之间随机到达车站，求：(1) 等候不到 5 min 就乘上车的概率；(2) 等候超过 10 min 才乘上车的概率。

**思路**： 以 7:00 为 0 时刻，把"随机到达"建模为 $t$ 均匀落在 $\Omega = [0,30]$。车在 $0, 15, 30$ 到站，等候时间 $W(t)$ 是分段函数：$t \in [0,15)$ 时 $W = 15 - t$，$t \in [15,30)$ 时 $W = 30 - t$。两个问题都化成解不等式。

**解**： 取 $\Omega = [0,30]$，$m(\Omega) = 30$。

(1) 等候不到 5 min：$t\in[0,15)$ 时 $15 - t < 5 \Rightarrow t \in (10,15)$；$t\in[15,30)$ 时 $30 - t < 5 \Rightarrow t\in(25,30)$。故
$$
S_A = (10,15) \cup (25,30), \quad m(S_A) = 10, \qquad P = \frac{10}{30} = \frac{1}{3}
$$
(2) 等候超过 10 min：$t\in[0,15)$ 时 $15 - t > 10 \Rightarrow t\in[0,5)$；$t\in[15,30)$ 时 $30 - t > 10 \Rightarrow t\in[15,20)$。故
$$
S_B = [0,5) \cup [15,20), \quad m(S_B) = 10, \qquad P = \frac{10}{30} = \frac{1}{3}
$$
:::

:::example 例 2 · 二维几何概型
**题目**： 在区间 $(0,1)$ 内任取两个数，求事件"两数之和小于 $\frac{6}{5}$"发生的概率。

**思路**： 以取到的两个数为坐标，样本空间是单位正方形；把不等式翻译成区域，取面积之比。直接算 $x + y < \frac{6}{5}$ 要分块，改用**对立面**——右上角那个小直角三角形。

**解**： 设两个数分别为 $x, y$，则
$$
\Omega = \{(x,y) : 0 < x < 1,\ 0 < y < 1\}, \qquad A = \{(x,y) : x + y < \tfrac{6}{5},\ (x,y) \in \Omega\}
$$
补集是直角三角形，两条直角边均为 $1 - \frac{1}{5} = \frac{4}{5}$，面积 $\frac{1}{2}\left(\frac{4}{5}\right)^2 = \frac{8}{25}$，故
$$
P(A) = \frac{S_A}{S_\Omega} = \frac{1 - \frac{1}{2}\left(\frac{4}{5}\right)^2}{1 \times 1} = \frac{17}{25}
$$

## 概率的定义与基本性质

#### 频率

在相同条件下进行的 $n$ 次试验中，事件 $A$ 发生的次数 $n_A$ 称为**频数**，比值

$$
f_n(A) = \frac{n_A}{n}
$$

称为事件 $A$ 发生的**频率**。

频率的性质：
1. $0 \le f_n(A) \le 1$；
2. $f_n(\Omega) = 1$；
3. 设 $A_1, A_2, A_3, \cdots$ 是 $\Omega$ 中任意两两互斥的事件（$A_iA_j = \varnothing,\ i \ne j$），则
   $$
   f_n(A_1 \cup A_2 \cup \cdots) = f_n(A_1) + f_n(A_2) + \cdots
   $$

#### 概率的统计定义

相同条件下的 $n$ 次重复试验中，当 $n \to \infty$ 时，频率 $f_n(A)$ 逐渐稳定于某个常数 $p$，称此常数 $p$ 为事件 $A$ 发生的**概率**，记作

$$
P(A) = p
$$

#### 概率的公理化定义

1933 年，苏联数学家**科尔莫戈罗夫**在总结前人大量研究成果的基础上，建立了概率的公理化法则。

设随机试验 $E$ 的样本空间为 $\Omega$，对 $\Omega$ 中每一事件 $A$ 赋予一个实数 $P(A)$，称为事件 $A$ 的**概率**。若集合函数 $P(\cdot)$ 满足下列三条：

| 公理 | 名称 | 内容 |
| :--- | :--- | :--- |
| 1 | **非负性** | 对每个事件 $A$，$P(A) \ge 0$ |
| 2 | **规范性** | 对必然事件 $\Omega$，$P(\Omega) = 1$ |
| 3 | **可列可加性** | 设 $A_1, A_2, \cdots$ 是 $\Omega$ 中任意两两互斥的事件（$A_iA_j = \varnothing,\ i\ne j$），则 $P\left(\bigcup_{k=1}^{\infty} A_k\right) = \sum_{k=1}^{\infty} P(A_k)$ |

#### 概率的性质

设 $A, B, A_1, \cdots, A_n$ 均为事件，由三条公理可推出以下六条性质：

| 序号 | 名称 | 内容 |
| :--- | :--- | :--- |
| (1) | 有界性 | $0 \le P(A) \le 1$ |
| (2) | 规范性 | $P(\varnothing) = 0$，$P(\Omega) = 1$ |
| (3) | **有限可加性** | 若 $A_1,\cdots,A_n$ 两两互斥，则 $P\left(\bigcup\limits_{k=1}^{n} A_k\right) = \sum\limits_{k=1}^{n} P(A_k)$ |
| (4) | 对立事件 | $P(\bar A) = 1 - P(A)$ |
| (5) | **减法公式** | $P(A - B) = P(A) - P(AB)$；特别地 $B \subset A$ 时 $P(A-B) = P(A) - P(B)$ 且 $P(A) \ge P(B)$ |
| (6) | **加法公式** | $P(A + B) = P(A) + P(B) - P(AB)$ |

:::tip 证明 · 性质 (2)
注意 $\Omega = \Omega \cup \varnothing \cup \varnothing \cup \cdots$ 各项两两互斥，由可列可加性
$$
P(\Omega) = P(\Omega) + P(\varnothing) + P(\varnothing) + \cdots = 1
$$
左端是有限数，故只能 $P(\varnothing) + P(\varnothing) + \cdots = 0$，即 $P(\varnothing) = 0$。
:::

:::tip 证明 · 性质 (3)：有限可加性
令 $A_{n+1} = A_{n+2} = \cdots = \varnothing$，这列事件仍两两互斥，且 $\bigcup\limits_{k=1}^{\infty} A_k = \bigcup\limits_{k=1}^{n} A_k$，由可列可加性与 $P(\varnothing)=0$
$$
P\left(\bigcup_{k=1}^{n} A_k\right) = \sum_{k=1}^{\infty} P(A_k) = \sum_{k=1}^{n} P(A_k)
$$
:::

:::tip 证明 · 性质 (4)
$A$ 与 $\bar A$ 互斥且 $A \cup \bar A = \Omega$，由有限可加性与规范性
$$
P(A) + P(\bar A) = 1 \Longrightarrow P(\bar A) = 1 - P(A)
$$
顺带得到 $P(A) \le 1$——公理 1 里的上界其实不必单列。
:::

:::tip 证明 · 性质 (5)：减法公式
把 $A$ 拆成互斥的两块：$A = (A - B) \cup AB$，且 $(A-B) \cap AB = \varnothing$，由有限可加性
$$
P(A) = P(A-B) + P(AB) \Longrightarrow P(A-B) = P(A) - P(AB)
$$
**推论（单调性）**：若 $B \subset A$，则 $AB = B$，故 $P(A-B) = P(A) - P(B) \ge 0$，即 $P(B) \le P(A)$——大事件的概率不小于小事件。
:::

:::tip 证明 · 性质 (6)：加法公式
把 $A + B$ 拆成互斥的两块：$A \cup B = A \cup (B - AB)$，且 $A \cap (B-AB) = \varnothing$，由有限可加性与性质 (5)
$$
P(A+B) = P(A) + P(B-AB) = P(A) + P(B) - P(AB)
$$
推广到三个事件（容斥原理）：
$$
P(A+B+C) = P(A)+P(B)+P(C) - P(AB) - P(AC) - P(BC) + P(ABC)
$$
再推广到 $n$ 个事件：
$$
P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i} P(A_i) - \sum_{i<j} P(A_iA_j) + \sum_{i<j<k} P(A_iA_jA_k) - \cdots + (-1)^{n-1} P(A_1A_2\cdots A_n)
$$
:::

:::example 例 1 · 选择题：P(AB) = 0 的含义
**题目**： 如果事件 $A$ 与 $B$ 同时发生的概率 $P(AB) = 0$，则（　　）

A. $A$ 与 $B$ 互斥　　B. $AB$ 是不可能事件　　C. $P(A) = 0$ 或 $P(B) = 0$　　D. $A$ 与 $B$ 可能同时发生

**思路**： 逐个用"反例"检验。互斥要求 $AB = \varnothing$，比 $P(AB) = 0$ 强；"不可能事件"同样要求 $AB = \varnothing$；C 更经不起检验——取几何概型里"恰好落在某一点"的事件即可。

**解**： 取几何概型中的事件即可反驳 A、B、C：概率为 $0$ 的事件未必是空集，落在某点上的事件概率为 $0$ 却"可能发生"。故选 **D**。

**评注**： "概率为 $0$"是**测度**层面的结论，"不可能"是**集合**层面的结论，两者只在古典概型中重合——这是全章最容易被忽视的一条边界。
:::

> **注意**：概率为 $0$ 的事件**不一定**是不可能事件；概率为 $1$ 的事件**不一定**是必然事件。这两条"反之"只在**古典概型**中才成立。

> **案例**：朝半径为 $5$ 的圆形靶射击，"射中圆心"的概率为 $0$，但这确实可能发生——几何概型中概率等于面积之比，而圆心的面积为 $0$。

:::example 例 2 · 对立事件的应用
**题目**： 某人忘记密码的最后一位是哪个数字，他从 $0,1,\cdots,9$ 中随机地选一个，求他能在 3 次尝试之内解开密码的概率。

**思路**： 样本点是"密码的取值"，$\Omega = \{0,1,\cdots,9\}$。正面要分"第 1 次中""第 2 次中""第 3 次中"，走反面只剩一种情形：正确数字在他没试过的 7 个数字里。

**解**： 设 $A$ = "3 次之内解开"，则 $\bar A$ = "3 次都没猜中"，即正确数字落在没试过的 7 个中：
$$
P(\bar A) = \frac{7}{10} \Longrightarrow P(A) = 1 - \frac{7}{10} = \frac{3}{10}
$$

**评注**： ① 正面要分类、反面只有一种时，一律走反面；② 结果 $\frac{3}{10}$ 与直觉（3 次机会 ÷ 10 个数字）吻合，可作验算；③ 样本点选"密码取值"而不是"尝试过程"，是本题不绕弯路的关键。
:::

:::example 例 3 · 比较概率大小
**题目**： 试比较 $P(A)$、$P(AB)$、$P(A+B)$、$P(A)+P(B)$ 的大小。

**思路**： 先用事件的包含关系排序，再用加法公式收尾。

**解**： 由 $AB \subset A \subset A+B$ 及单调性得
$$
P(AB) \le P(A) \le P(A+B)
$$
又 $P(A+B) = P(A) + P(B) - P(AB)$，而 $P(AB) \ge 0$，故 $P(A+B) \le P(A) + P(B)$。综上
$$
P(AB) \le P(A) \le P(A+B) \le P(A) + P(B)
$$

**评注**： 这类题不给数值，靠的是**包含关系 + 非负性**两条。注意等号成立的时机：$P(AB) = P(A)$ 当且仅当 $A \subset B$；$P(A+B) = P(A)+P(B)$ 当且仅当 $A, B$ 互斥。
:::

:::example 例 4 · 减法公式与对立事件
**题目**： 设 $P(A) = 0.7$，$P(A - B) = 0.3$，求 $P(\overline{AB})$。

**思路**： $A - B$ 用减法公式展开即可解出 $P(AB)$，再对 $AB$ 取补。

**解**： 由 $P(A-B) = P(A) - P(AB) = 0.3$ 且 $P(A) = 0.7$，得
$$
P(AB) = 0.7 - 0.3 = 0.4, \qquad P(\overline{AB}) = 1 - P(AB) = 0.6
$$

**评注**： 减法公式 $P(A-B) = P(A) - P(AB)$ 是"已知差事件求交"的唯一通道；注意它**不是** $P(A) - P(B)$（后者只在 $B \subset A$ 时才对）。
:::

:::example 例 5 · 对偶律的用法
**题目**： $A, B$ 是两个随机事件，已知 $P(AB) = P(\bar A \bar B)$，$P(A) = p$，求 $P(B)$。

**思路**： 题目里"对立事件较多"时，先考虑用对偶律把 $\bar A \bar B$ 并成一个整体：$\bar A \bar B = \overline{A + B}$。

**解**： 由对偶律与加法公式
$$
P(\bar A \bar B) = P(\overline{A+B}) = 1 - P(A+B) = 1 - P(A) - P(B) + P(AB)
$$
代入 $P(\bar A \bar B) = P(AB)$，两端消去 $P(AB)$：
$$
1 - P(A) - P(B) = 0 \Longrightarrow P(B) = 1 - P(A) = 1 - p
$$

**评注**： "$\bar A \bar B = \overline{A+B}$"与"$\bar A \cup \bar B = \overline{AB}$"是把**乘积的补**与**和的补**互相转换的两个开关，凡是式子里出现多个横线，先把它们收成一个整体再说。
:::

## 小结

1. **试验**是实验和观察的统称；同时满足**可重复**、**结果不止一个且事先已知**、**事前不能确定**三条的才是**随机试验**，只满足后两条的现象叫**随机现象**——概率论的研究对象就是随机现象，主要是大量重复的随机试验。每个不可再分的结果是**样本点** $\omega$，全体样本点组成**样本空间** $\Omega$（至少两个样本点；有限或可列为**离散**，不可列无限为**连续**）。
2. **随机事件**是 $\Omega$ 的子集，"发生"就是试验结果落在它里面——所以只有陈述句才谈得上发生与否。单点集是**基本事件**（两两互不相容），$\varnothing$ 是**不可能事件**、$\Omega$ 是**必然事件**；"骰子掷出 7"对应的是 $\varnothing$ 而不是 $\{7\}$，因为 $\{7\}$ 根本不是 $\Omega$ 的子集。
3. 事件是集合，关系照集合来：**包含** $A \subset B$ 是"$A$ 发生必导致 $B$ 发生"，**相等**是互相包含，**互斥**是 $AB = \varnothing$，**对立**是 $AB = \varnothing$ 且 $A \cup B = \Omega$（记作 $\bar A$）。一句话记牢：**对立 = 互斥 + 完备**——互斥只保证不同时发生，对立还保证必定有一个发生。
4. 三种运算各有口头翻译：**并**（和事件）$A \cup B = A + B$ 是"至少一个发生"，**交**（积事件）$A \cap B = AB$ 是"同时发生"，**差** $A - B = A\bar B$ 是"$A$ 发生而 $B$ 不发生"。
5. 运算律里真正要练熟的是两条：**分配律**（并对交、交对并各一条，化简与拆项都靠它）和**对偶律**（横线推进去、交并互换，并可推广到可列个事件）。注意事件运算**一般不能去括号**：$A - (B - C) \ne (A - B) + C$，遇到差事件一律先化成"交补"再动。
6. **古典概型**的两个条件是**有限性**与**等可能性**，此时 $P(A) = k/n$。全部计算都落在"数样本点"上：乘法原理、加法原理、排列 $A_n^m$、组合 $C_n^m$、可重复排列 $n^m$。**分子分母必须同一口径**（有没有放回、分不分顺序），这是这类题唯一的死穴。
7. 古典概型的三条套路：**"至少"先走对立面** $1 - P(\bar A)$；**"只有某次"必须把其余事件取补**，而"恰有"靠枚举各种位置再并起来；**分组问题**里若组本身有区别（班级、编号），组合数相乘即可，**不要再乘组数的阶乘**。
8. **几何概型**把等可能从有限推广到无限：随机点等可能落在区域内任意位置时 $P(A) = m(G)/m(\Omega)$，其中度量是长度、面积或体积——**只与度量成正比，与位置和形状无关**。于是单点的度量恒为 $0$，$P(\{\omega\}) = 0$，开区间与闭区间在计算中毫无差别。
9. **频率** $f_n(A) = n_A/n$ 满足非负、规范、两两互斥时可加三条性质；$n \to \infty$ 时它稳定于某个常数，这个稳定值就是**概率的统计定义**——直观，但算不出具体值。1933 年**科尔莫戈罗夫**的公理化定义把它一次性立住：**非负性**、**规范性**、**可列可加性**三条公理。
10. 由三条公理推出六条性质：**有界性**、$P(\varnothing) = 0$、**有限可加性**、**对立事件** $P(\bar A) = 1 - P(A)$、**减法公式** $P(A - B) = P(A) - P(AB)$（不是 $P(A) - P(B)$）、**加法公式** $P(A + B) = P(A) + P(B) - P(AB)$（勿漏 $-P(AB)$，只有互斥时才能直接相加），并能推广成**容斥公式**。
11. 全章最容易被忽视的一条边界：**"概率为 $0$"是测度层面的结论，"不可能"是集合层面的结论**，两者只在**古典概型**里重合。所以概率为 $0$ 的事件不一定是不可能事件，概率为 $1$ 的也不一定是必然事件——几何概型里"射中圆心"就是现成的例子。
