## 变量与常量

### 变量

**变量**（Variable）是内存中一块被命名的存储空间，用于存放程序运行期间可以改变的数据。把它想成一个带标签的盒子：标签是变量名，盒子里装的是数据值。它的核心规则只有一条——**一个变量在同一时刻只能存一个值**，赋新值就是覆盖旧值。

#### 声明与赋值

声明一个变量要给出两样信息：**数据类型**和**变量名**。

```
数据类型 变量名;            // 仅声明，不赋初值
数据类型 变量名 = 初始值;    // 声明同时赋初值（推荐）
```

```cpp
int a;              // 创建一个名为 a 的 int 类型变量（值未定义！）
int b = 10;         // 创建并初始化为 10
int c, d, e;        // 同时声明三个同类型变量（不推荐：可读性差）
int x = 1, y = 2;   // 同时声明并初始化两个变量
```

| 组成部分 | 说明 |
| :--- | :--- |
| **数据类型** | 限定变量中能存储什么类型的数据。C++ 是**静态类型语言**——类型一旦声明就不能改变 |
| **变量名** | 容器的名字，之后通过它来访问和修改数据，遵循标识符命名规则 |
| **初始值** | 声明时赋予的初始数据 |

> **易错点**：C++ **不会自动初始化局部变量**。声明了却不赋初值，变量里装的就是内存中残留的随机垃圾值，使用它就是使用一个随机数，出错时无从排查。Java 的处理相反——局部变量使用前必须显式赋值，否则编译报错。把"声明即初始化"当成默认动作，写 `int a = 0;` 而不是 `int a;`。

#### 使用原则

在写法上有三条规则要守住：

1. **变量名不能重复**——同一作用域内不能定义同名变量。
2. **变量使用前最好赋初值**——C++ 不强制，但不赋初值等于使用随机垃圾值。
3. **一条语句可以定义多个变量**（如 `int a = 10, b = 20;`），但会降低可读性，不推荐。

下面这段程序演示变量最核心的语义——同一个变量在运行过程中被改了两次，旧值被新值覆盖：

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 25;
    cout << "年龄：" << age << endl;     // 输出：年龄：25

    age = 26;                            // 修改变量的值（旧值 25 被覆盖）
    cout << "明年：" << age << endl;     // 输出：明年：26

    return 0;
}
```

> **例 1（公交车乘客计数）** 模拟一辆公交车经过三个站台后的乘客数量变化。初始车上有 10 人，第一站下 3 人上 5 人，第二站下 2 人上 8 人，第三站下 6 人上 1 人。求最终乘客人数。

**思路**：这是一个状态追踪问题——用一个变量 `count` 保存当前人数，每经过一站就用 `count = count - 下车 + 上车` 更新它。变量天然适合扮演这种"动态状态容器"的角色。

**解**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 10;                  // 初始：10 人
    count = count - 3 + 5;           // 第一站：下3上5 → 12
    count = count - 2 + 8;           // 第二站：下2上8 → 18
    count = count - 6 + 1;           // 第三站：下6上1 → 13
    cout << "最终乘客人数：" << count << endl;  // 输出：13
    return 0;
}
```

这个例子展示了变量最核心的语义——等号 `=` 在编程中**不是数学上的"等于"，而是赋值**。数学里 `count = count - 3 + 5` 是一个矛盾方程，在编程里它是一句合法指令：读取 `count` 的当前值，计算 `count - 3 + 5`，再把结果写回 `count`。理解了这个差异，就迈过了从数学思维到编程思维的第一道门槛。

### 常量

**常量**（Constant）是一旦定义就不可更改的数据，用来表达圆周率、一周的天数、最大连接数这类运行期间不应该变的值。C++ 提供三种定义方式，取舍很清楚：**日常常量用 `const`，一组相关的整型常量用 `enum`，`#define` 只在条件编译等少数场景保留**。

#### 宏常量

宏常量是 C 语言的遗产——在**预处理阶段**由预处理器进行纯文本替换，不占用内存空间，也没有类型检查：

```cpp
#include <iostream>
using namespace std;
#define DAY 7                    // 通常放在 using namespace std; 下方

int main() {
    cout << "一周有 " << DAY << " 天" << endl;   // 输出：一周有 7 天
    // DAY = 8;                 // 错误！宏常量不可修改
    return 0;
}
```

它的工作机制就是"查找替换"：预处理器在编译前把代码中所有的 `DAY` 换成 `7`。优点是简单直接、不占内存；代价是**没有类型检查**（`DAY` 可以被当作 `int`、`double` 或任何类型使用，编译器不会提醒你类型是否恰当），也**没有作用域概念**（从定义处到文件末尾全程有效，可能误覆盖其他代码中的同名标识符）。

#### const 常量

`const` 是 C++ 推荐的常量定义方式——它有明确的类型、有作用域、可以被调试器识别，编译器还可能把它优化为立即数而不实际分配内存：

```cpp
#include <iostream>
using namespace std;

int main() {
    const double PI = 3.1415926;     // const 常量，类型明确
    const int MAX_SIZE = 100;

    double r = 5.0;
    double area = PI * r * r;
    cout << "面积：" << area << endl;  // 输出：面积：78.5398

    // PI = 3.14;                    // 错误！const 常量不可修改
    return 0;
}
```

> **推荐**：优先用 `const` 而非 `#define` 定义常量。类型安全、有作用域、能被调试器识别这三点在大型项目里尤其重要；`#define` 只留给条件编译（`#ifdef`）和头文件保护这类场景。

#### 枚举常量

需要定义**一组相关联的整型常量**时，`enum` 比逐个写 `const int` 更简洁，也更有语义：

```cpp
#include <iostream>
using namespace std;

enum Week { MON = 1, TUE, WED, THU, FRI, SAT, SUN };
// MON=1, TUE=2, WED=3, THU=4, FRI=5, SAT=6, SUN=7

int main() {
    Week today = WED;
    cout << "今天是星期" << today << endl;   // 输出：今天是星期3
    return 0;
}
```

枚举的规则有三条：

- 第一个枚举值可以手动指定起始值（如 `MON = 1`），后续值自动递增（`TUE = 2`、`WED = 3`……）。
- 如果第一个值不指定，默认从 `0` 开始。
- 枚举值本质上是**有名字的整数**——`WED` 在程序中等价于 `3`，但它比裸数字 `3` 更具可读性。

三种方式的差别可以并列看清：

| 方式 | 语法 | 处理阶段 | 类型检查 | 作用域 | 调试可见 | 推荐场景 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `#define` | `#define PI 3.14` | 预处理，纯文本替换 | 无 | 无（从定义处到文件末尾） | 不可见（已被替换成字面量） | 条件编译、头文件保护 |
| `const` | `const double PI = 3.14;` | 编译时 | 有 | 有 | 可见 | **日常常量定义的首选** |
| `enum` | `enum { RED, GREEN, BLUE };` | 编译时 | 有（限整型） | 有 | 可见 | 一组相关联的整型常量 |

内存占用上，`#define` 是纯文本替换、不占内存；`const` 有实体、可能占用内存——只是编译器常常直接把它换成字面量。

## 数据类型

变量解决了"在哪存"，"存什么"则由数据类型决定。C++ 是**静态类型语言**——每个变量在创建时必须明确自己的类型，编译器据此决定分配多少内存、能进行哪些操作、值如何解释。理解数据类型是理解 C++ 内存模型的起点。

### 基本数据类型

C++ 的基本数据类型分为以下五类：

| 类型 | 关键字 | 占用空间 | 取值范围 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **整型** | `int` | 4 字节 | $-2^{31} \sim 2^{31}-1$（约 ±21 亿） | 最常用的整数类型 |
| **单精度浮点型** | `float` | 4 字节 | 约 7 位有效数字 | 内存敏感场景（如图形学） |
| **双精度浮点型** | `double` | 8 字节 | 约 15~16 位有效数字 | **小数默认首选** |
| **字符型** | `char` | 1 字节 | ASCII 码（-128 ~ 127 或 0 ~ 255） | 单个字符 |
| **布尔型** | `bool` | 1 字节 | `true`（非 0，通常为 1）或 `false`（0） | 逻辑判断 |

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 20;               // 整型：年龄
    float height = 1.75f;       // 单精度浮点型：身高（注意 f 后缀！）
    double pi = 3.1415926535;   // 双精度浮点型：圆周率
    char grade = 'A';           // 字符型：等级
    bool isPassed = true;       // 布尔型：是否通过

    cout << "年龄：" << age << endl;
    cout << "身高：" << height << endl;
    cout << "圆周率：" << pi << endl;
    cout << "等级：" << grade << endl;
    cout << "是否通过：" << isPassed << endl;   // 输出 1（true）
    return 0;
}
```

> **注意**：`float` 类型的字面量必须加 **`f` 或 `F` 后缀**——写 `1.75f`。不加后缀（如 `1.75`）时编译器默认把它当作 `double`，赋值给 `float` 变量会触发隐式类型转换，丢失精度并可能给出警告。同理，`long` 类型字面量需要加 `L` 后缀（如 `100L`）。这和 Java 的规则一致。

#### 整型

C++ 只定义了**带符号**的整型（符号位占最高位，0 表示正、1 表示负），因此正数的范围比负数少一个——`0` 占据了符号位为 0 的一个编码位置。整型的实际占用空间取决于编译器和平台，下表是当前主流平台（32/64 位 Windows/Linux）上的实际情况：

| 类型 | 占用空间 | 取值范围 | 使用建议 |
| :--- | :--- | :--- | :--- |
| `short`（`short int`） | 2 字节 | $-2^{15} \sim 2^{15}-1$（-32768 ~ 32767） | 极少使用，仅在内存极其受限的场景 |
| `int` | 4 字节 | $-2^{31} \sim 2^{31}-1$（约 -21 亿 ~ 21 亿） | **整数默认首选** |
| `long`（`long int`） | 4 字节（Windows）或 8 字节（Linux 64 位） | 与 `int` 相同或更大 | 跨平台代码中避免使用（长度不确定） |
| `long long`（`long long int`） | 8 字节 | $-2^{63} \sim 2^{63}-1$ | 需要超过 21 亿的整数时使用 |

> **注意**：C++ 标准只规定了各类型的**最小范围**而非精确长度，这导致 `long` 在 Windows（4 字节）和 Linux 64 位（8 字节）上不一致。需要确保长度时可以用 `<cstdint>` 中的固定宽度整型（`int32_t`、`int64_t` 等），日常编码中 `int` 与 `long long` 已经够用。Java 在这方面更严格——`int` 永远是 4 字节，`long` 永远是 8 字节，没有任何平台差异。

#### 字符型

`char` 占 **1 个字节**（8 位），存储的是字符对应的 **ASCII 码**，本质是一个整数：

```cpp
char ch1 = 'a';        // 存储 ASCII 码 97
char ch2 = 'A';        // 存储 ASCII 码 65
char ch3 = '0';        // 存储 ASCII 码 48（不是数字 0！）
```

常用 ASCII 码：`'a'`→97，`'A'`→65，`'0'`→48，`'\n'`→10，`'\t'`→9，`'\\'`→92。这与 Java 的 `char`（2 字节，Unicode 编码）不同——C++ 的 `char` 只能表示 ASCII 字符集内的字符（英文字母、数字、常见标点），不能直接表示中文等 Unicode 字符。

当需要在字符串中表示无法直接键入的特殊字符时，使用**转义字符**——以反斜线 `\` 开头：

| 转义字符 | 含义 | ASCII 码 |
| :--- | :--- | :--- |
| `\n` | 换行（LF），光标移到下一行开头 | 10 |
| `\t` | 水平制表（Tab），跳到下一个制表位 | 9 |
| `\\` | 反斜线字符 `\` 本身 | 92 |
| `\'` | 单引号字符 | 39 |
| `\"` | 双引号字符 | 34 |
| `\0` | 空字符（字符串结束标志） | 0 |

#### 浮点型

浮点型只有两种，差别在精度和字节数：

| 类型 | 字节数 | 有效数字位数 | 常量后缀 |
| :--- | :--- | :--- | :--- |
| `float`（单精度） | 4 | 约 7 位 | `f` 或 `F`（**必须加**） |
| `double`（双精度） | 8 | 约 15~16 位 | 可省略（小数默认就是 `double`） |

```cpp
float  f = 3.14f;          // float：f 后缀不可省略
double d = 3.1415926535;   // double：默认类型，无需后缀
double e = 1.5e3;          // 科学计数法：1.5 × 10³ = 1500
```

> **注意**：浮点数存在**精度丢失**问题。这不是 C++ 的 bug，而是所有使用 IEEE-754 标准的语言（C、Java、Python、JavaScript）共有的现象——大多数十进制小数无法用有限位二进制精确表示。在涉及金额、利率等需要精确计算的场景，应使用整数（以"分"为单位）或专门的十进制计算库。

#### 布尔型

`bool` 只有两个值：`true`（真，通常存储为整数 `1`）和 `false`（假，存储为整数 `0`）。这里藏着 C++ 与 Java 的一个关键差异：

```cpp
#include <iostream>
using namespace std;

int main() {
    bool flag = true;
    cout << flag << endl;       // 输出：1（而非 "true"）

    int x = 10;
    if (x) {                    // C++ 中非零值可直接作为条件！
        cout << "x 非零" << endl;
    }
    return 0;
}
```

> **C++ vs Java**：C++ 中非零值自动视为 `true`、零值视为 `false`——`if (10)` 是合法的（条件为真）。Java 则要求条件必须是 `boolean` 类型，`if (10)` 会直接编译报错。这是 C++ 从 C 语言继承的灵活（危险）特性，它让代码更简洁，也更容易引入隐式 bug。

### 字符串类型

结论先给：字符串有两种表示方式，**自己写新代码时优先用 C++ 风格的 `string`**，但 C 风格的字符数组必须能读懂，因为已有代码和竞赛题里它依然常见。

| 方式 | 语法 | 来源 | 头文件 | 特点 |
| :--- | :--- | :--- | :--- | :--- |
| **C 风格字符串** | `char str[] = "hello";` | C 语言 | `<cstring>` | 本质是字符数组，以 `\0` 结尾，操作不便 |
| **C++ 风格字符串** | `string str = "hello";` | C++ 标准库 | `<string>` | 封装好的类，支持 `+` 拼接、`length()` 等，**推荐使用** |

```cpp
#include <iostream>
#include <string>            // C++ 风格 string 必须包含此头文件
using namespace std;

int main() {
    // C 风格字符串（字符数组）
    char cstr[] = "Hello C";

    // C++ 风格字符串（推荐）
    string cppstr = "Hello C++";

    cout << cstr << endl;              // 输出：Hello C
    cout << cppstr << endl;            // 输出：Hello C++
    cout << cppstr.length() << endl;   // 输出：8（字符串长度）

    // C++ string 支持 + 拼接
    string name = "张三";
    string greeting = "你好，" + name;
    cout << greeting << endl;          // 输出：你好，张三

    return 0;
}
```

> **建议**：两种写法都要能看懂，因为既有代码和竞赛题里两种风格都可能出现；但自己编写新代码时，`string` 更安全、功能更强、代码更简洁。

### 限定符

限定符不改数据本身，只调整基本类型的长度和符号属性，回答"这个类型到底占多少字节、能不能表示负数"。

#### sizeof 运算符

`sizeof` 是 C++ 的**运算符**而非函数——它在编译时计算数据类型或变量所占的内存字节数，返回类型为 `size_t`（一个无符号整型）：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "int: " << sizeof(int) << " 字节" << endl;         // 4
    cout << "double: " << sizeof(double) << " 字节" << endl;   // 8
    cout << "char: " << sizeof(char) << " 字节" << endl;       // 1
    cout << "bool: " << sizeof(bool) << " 字节" << endl;       // 1

    double d = 3.14;
    cout << "变量 d: " << sizeof(d) << " 字节" << endl;        // 8
    // sizeof 可以作用于变量，此时括号可省略：
    cout << "变量 d: " << sizeof d << " 字节" << endl;         // 8（同上）

    return 0;
}
```

学习新类型时用 `sizeof` 验证它实际占多少空间是个好习惯——不同平台和编译器下数值可能不同，亲眼看到比死记硬背可靠。

> **易错点**：`sizeof` 在编译阶段就求值，编译器直接把它替换成常量，所以它**不能用来看动态分配的内存有多大**。更要小心 `sizeof(arr)`——当 `arr` 是函数参数时它已经退化为指针，返回的是指针大小（4 或 8 字节），而不是数组的实际长度。

#### 短整型与长整型

`short` 和 `long` 这两个限定符用于调整整型的长度：

| 类型 | 占用空间（主流平台） | 取值范围 |
| :--- | :--- | :--- |
| `short`（或 `short int`） | 2 字节 | $-2^{15} \sim 2^{15}-1$ |
| `int` | 4 字节 | $-2^{31} \sim 2^{31}-1$ |
| `long`（或 `long int`） | 4 或 8 字节（平台相关） | 至少 $-2^{31} \sim 2^{31}-1$ |
| `long long`（或 `long long int`） | 8 字节 | $-2^{63} \sim 2^{63}-1$ |

```cpp
short s = 32767;          // 2 字节，范围 -32768~32767
long l = 2147483647L;     // 注意 L 后缀
long long ll = 9223372036854775807LL;  // 超长整型
```

限定 `int` 时常可省略 `int` 关键字（`short` 等价于 `short int`，`long` 等价于 `long int`），但限定其他类型（如 `long double`）时不能省略。

#### 有符号与无符号

默认情况下 C++ 的整型和字符型是**有符号**的（`signed` 通常省略不写）。加上 `unsigned` 可以将其变为无符号类型——不设符号位，所有位全部用于表示数值，范围翻倍：

| 类型 | 取值范围 |
| :--- | :--- |
| `(signed) int` | $-2^{31} \sim 2^{31}-1$（`signed` 通常省略） |
| `unsigned int` | $0 \sim 2^{32}-1$（约 0 ~ 42 亿） |
| `(signed) char` | $-128 \sim 127$ |
| `unsigned char` | $0 \sim 255$ |

```cpp
unsigned int positive = 4294967295U;   // U 后缀表示无符号
unsigned char byte = 255;              // 0~255
```

> **注意**：无符号类型有一个危险陷阱——当有符号和无符号混合运算时，C++ 会将有符号数**隐式转换为无符号数**。`-1` 转成 `unsigned int` 会变成一个巨大的正数（4294967295），这在比较和循环中可能产生反直觉的结果。除非确实需要无符号（如位运算、字节处理），日常开发使用有符号整型即可。

### 数值类型转换

结论先给：表达式里混用不同类型时，编译器按"低精度向高精度看齐"自动转换；反过来把高精度塞进低精度必须显式写出，并自己承担精度或溢出的损失。

#### 隐式转换

编译器会自动将**低精度**类型转换为**高精度**类型，以保证计算结果不丢失精度。精度从低到高的顺序为：

```
char/short → int → unsigned int → long → unsigned long → long long → float → double → long double
```

```cpp
int a = 10;
double b = 3.14;
auto c = a + b;    // a 被自动提升为 double，c 的类型为 double，值为 13.14

int x = 15;
double f1 = x / 2;        // 整数除法：15/2=7 → f1=7.0（丢失小数！）
double f2 = x / 2.0;      // 混合除法：15/2.0=7.5 → f2=7.5（正确）
```

> **易错点**：`15 / 2` 的结果是 `7` 而不是 `7.5`。两个操作数都是 `int`，所以先执行**整数除法**，小数部分被截断（不是四舍五入），得到 `7`，然后才把 `7` 转为 `double` 赋给 `f1`——此时小数部分已经永久丢失了。而 `15 / 2.0` 中 `2.0` 是 `double` 类型，触发隐式转换后 `15` 被提升为 `double` 再执行浮点除法，结果才对。**运算时数据的类型，比赋值目标的类型更早决定结果。**

#### 显式转换

当你需要将高精度类型转为低精度类型时（可能丢失数据），必须显式进行强制转换——这是你在告诉编译器："我知道可能丢失数据，我接受这个风险。"C++ 提供两种语法：

| 方式 | 语法 | 特点 |
| :--- | :--- | :--- |
| **C 风格** | `(目标类型) 表达式` | 简洁但不够安全，不区分转换意图 |
| **C++ 风格** | `static_cast<目标类型>(表达式)` | 编译时检查，意图明确，**推荐使用** |

```cpp
// C 风格转换
int a = (int)5.4;        // a = 5，小数部分截断

// C++ 风格转换（推荐）
int b = static_cast<int>(5.4);   // b = 5
double d = 3.14159;
int c = static_cast<int>(d);     // c = 3

// 强制转换可能导致溢出
int n = 130;
char ch = static_cast<char>(n);  // ch 的值取决于 char 是否为 signed
                                  // signed char 时 ch = -126（溢出回绕）
```

> **建议**：优先使用 `static_cast` 而非 C 风格强制转换。`static_cast` 在编译时会进行更严格的类型检查，代码审查时也更容易被检索到。另外三种 C++ 转换（`const_cast`、`dynamic_cast`、`reinterpret_cast`）各有专门用途，见 C++程序设计基础-8 面向对象编程。

赋值过程中还有一类静默发生的转换，值得单独盯一眼：

```cpp
double d = 5 / 2;           // d = 2.0（先整数除法，再转为 double）
double e = 5.0 / 2;         // e = 2.5（混合运算，正确）
double f = static_cast<double>(5) / 2;  // f = 2.5（显式转换，最清晰）

float g = 1.5;              // 警告！1.5 是 double，赋值给 float 丢失精度
float h = 1.5f;             // 正确：f 后缀指定为 float 字面量
```

> **易错点**：`float g = 1.5;` 这行的类型收缩是隐式发生的，编译器通常只给一条警告而不是错误，容易被忽略。字面量后缀写全（`1.5f`）是最省事的做法。

## 运算符

有了数据，下一步是**计算**。运算符是 C++ 提供的计算工具，每一种都对应一种特定的数据处理方式：算术运算符做四则运算，赋值运算符把结果写回变量，关系与逻辑运算符负责判断，逗号和三目运算符则用来把多个表达式压进一行。真正需要留意的不是"有哪些运算符"，而是**优先级、结合性、以及几个静默失效的陷阱**。

### 算术运算符

算术运算符处理最基本的数学计算。`+` `-` `*` `/` 和数学中的概念一致，但 `%`（取模）是编程语言特有的——它返回整数除法的余数。

| 运算符 | 名称 | 优先级 | 示例 |
| :--- | :--- | :--- | :--- |
| `*` | 乘法 | 3 | `a * b` |
| `/` | 除法 | 3 | `a / b` |
| `%` | 取模（取余） | 3 | `a % b` |
| `+` | 加法 | 4 | `a + b` |
| `-` | 减法 | 4 | `a - b` |

优先级上 `*` `/` `%` 高于 `+` `-`，与数学中的"先乘除后加减"一致。

```cpp
int a = 10, b = 3;
cout << a + b << endl;    // 13
cout << a - b << endl;    // 7
cout << a * b << endl;    // 30
cout << a / b << endl;    // 3  （整数相除得整数，小数截断）
cout << a % b << endl;    // 1  （10 除以 3 余 1）
```

> **注意**：除法 `/` 在**整数相除时结果只保留整数部分**（截断，不是四舍五入）。`10 / 3` 得 `3`，而 `10.0 / 3` 或 `10 / 3.0` 得 `3.333...`。取模 `%` **只能用于整型**操作数——`10.0 % 3.0` 会编译错误。取模结果的**正负号与被除数相同**：`(-10) % 3` 得 `-1`，`10 % (-3)` 得 `1`。

### 赋值运算符

赋值运算符将右侧的值存入左侧的变量中；C++ 另外提供了"计算 + 赋值"的复合写法，让 `a = a + b` 这类代码更短。

#### 简单赋值

`=` 把右边表达式的值写进左边的变量，结合性为**从右到左**——`a = b = c = 5` 会把 `5` 依次赋给 `c`、`b`、`a`，最终三者都是 `5`。

> **注意**：赋值运算符的优先级很低，仅高于逗号运算符。这也意味着 `a = b == c` 会先算 `b == c` 再把布尔结果赋给 `a`，而不是"先赋值再比较"。

#### 复合赋值

复合赋值把"算一次再写回"合并成一个运算符：

| 运算符 | 名称 | 示例 | 等价于 |
| :--- | :--- | :--- | :--- |
| `=` | 赋值 | `a = 5` | — |
| `+=` | 加等 | `a += b` | `a = a + b` |
| `-=` | 减等 | `a -= b` | `a = a - b` |
| `*=` | 乘等 | `a *= b` | `a = a * b` |
| `/=` | 除等 | `a /= b` | `a = a / b` |
| `%=` | 模等 | `a %= b` | `a = a % b` |

```cpp
int a = 10;
a += 5;    // a = 15（等价于 a = a + 5）
a -= 3;    // a = 12
a *= 2;    // a = 24
a /= 4;    // a = 6
a %= 4;    // a = 2
```

### 自增与自减运算符

`++` 和 `--` 是 C 语言发明的最有特色（也最容易混淆）的运算符——它们将变量的值加 1 或减 1。**单独使用**时前置和后置结果完全一样，但**参与表达式**时行为截然不同：

| 形式 | 名称 | 规则 |
| :--- | :--- | :--- |
| `++a` | 前置自增 | **先**将 a 的值 +1，**再**用新值参与表达式运算 |
| `a++` | 后置自增 | **先**用 a 的旧值参与表达式运算，**再**将 a 的值 +1 |
| `--a` | 前置自减 | **先**将 a 的值 -1，**再**用新值参与表达式运算 |
| `a--` | 后置自减 | **先**用 a 的旧值参与表达式运算，**再**将 a 的值 -1 |

```cpp
int a = 10, b = 10;
cout << ++a * 10 << endl;   // 先加：a=11，再用：11*10=110 → 输出 110
cout << b++ * 10 << endl;   // 先用：10*10=100，后加：b=11 → 输出 100
cout << "a=" << a << endl;  // 11
cout << "b=" << b << endl;  // 11
```

> **例 2（自增表达式的执行次序）** 分析下面这段代码的输出结果：`int f = 2, m = 2;` 之后执行 `int x = (f * m++) + m;`，`x` 是多少？

**思路**：按"从左到右、先取旧值再自增"的直觉推演，`m++` 会先返回 `m` 的旧值 `2` 参与 `f * m++`（得 `4`），然后 `m` 自增为 `3`；紧接着 `+ m` 里的 `m` 已经是 `3`。

但这里要先说清楚：**这段代码本身是错的**。同一表达式内既修改又读取同一个变量（`m++` 与 `+ m`），自 C++11 起就被标准判定为**未定义行为**（undefined behavior，UB）——标准不再规定各子表达式谁先求值，因此结果由编译器决定，换一个编译器或换一个优化级别都可能得到别的值。下面按照主流编译器的实际表现推演，目的正是为了看清"为什么不能这么写"。

**解**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int f = 2, m = 2;
    int x = (f * m++) + m;   // UB！仅用于演示，勿照抄
    cout << x << endl;       // 主流编译器输出 7
    return 0;
}
```

程序输出：

```
7
```

**评注**：这个题暴露了自增运算符在复杂表达式中的真正危险——`(f * m++) + m` **不是一个"结果依赖求值顺序"的表达式，而是一个未定义行为**。很多人以为"顺序不确定"只是"可能得到 7 也可能得到 6"，实际上标准对 UB 没有任何要求：优化器完全可以让这段代码输出任意值，甚至让周围无关的代码一起出错。

结论只有一条：**永远不要把自增自减运算符写进复杂表达式**。把 `m++` 单独写成一行，下一行再使用新值——清晰比简洁重要得多。

> **注意**：在 `for (int i = 0; i < n; i++)` 和 `for (int i = 0; i < n; ++i)` 里，对整型变量而言前置和后置**没有区别**，因为循环头第三条表达式的返回值没有人使用。但 C++ 社区习惯统一写 `++i`：对 STL 迭代器这类复杂类型，后置自增要先拷贝一份旧值再自增，存在不必要的开销，而 `++i` 是无脑安全的选择。

### 关系运算符

关系运算符用于比较两个值之间的大小关系，结果永远是 **`bool`** 类型——`true`（1）或 `false`（0）：

| 运算符 | 含义 | 示例 |
| :--- | :--- | :--- |
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |
| `>` | 大于 | `a > b` |
| `>=` | 大于等于 | `a >= b` |
| `<` | 小于 | `a < b` |
| `<=` | 小于等于 | `a <= b` |

> **注意**：务必区分 `=`（赋值）和 `==`（相等判断）。在 C++ 中 `if (a = 3)` 是**合法**的——它先将 `3` 赋给 `a`，然后判断 `a` 是否为非零（结果为 `true`）；Java 中同样写法会直接编译报错。C++ 这个从 C 语言继承的行为是无数 bug 的来源，一个防御性写法是把常量写在左边：`if (3 == a)`——如果你误写成 `if (3 = a)`，编译器会立刻报错，因为不能给字面量 `3` 赋值。

### 逻辑运算符

逻辑运算符用于连接多个布尔条件，构造更复杂的判断：

| 运算符 | 名称 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `!` | 非 | 取反，`true` 变 `false` | `!flag` |
| `&&` | 与 | 两边都为 `true` 才为 `true` | `a > 0 && b > 0` |
| `\|\|` | 或 | 至少一边为 `true` 即为 `true` | `a > 0 \|\| b > 0` |

优先级为 `!` > `&&` > `||`。

```cpp
int age = 20;
bool hasID = true;

// 两个条件都满足
if (age >= 18 && hasID) {
    cout << "可以进入" << endl;
}

// 满足任一条件即可
int score = 95;
if (score == 100 || score >= 90) {
    cout << "优秀" << endl;
}
```

> **注意**：`&&` 和 `||` 具有**短路特性**——`&&` 左边为 `false` 时右边不执行，`||` 左边为 `true` 时右边不执行。这个特性可以直接用来避免空指针检查：`if (ptr != nullptr && ptr->value > 0)` 中，如果 `ptr` 为空，右边的解引用根本不会发生。

### 逗号运算符

逗号运算符从左到右依次求值，整个表达式的值为**最后一个子表达式的值**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 2, b = 4, c = 6, x, y;

    x = (a + b, b + c);            // 先算 a+b=6（丢弃），再算 b+c=10 → x=10
    y = (a++, b++, a + b + c);     // a=3, b=5, c=6 → y=3+5+6=14

    cout << "x=" << x << ", y=" << y << endl;   // 输出：x=10, y=14
    return 0;
}
```

逗号运算符在日常业务代码中极少使用（会降低可读性），但在 `for` 循环头中同时操作多个变量时很常见：`for (int i = 0, j = n-1; i < j; i++, j--)`。这里的两个逗号都是逗号运算符。

### 三目（条件）运算符

三目运算符 `?:` 是 C++ 中唯一的**三目**运算符——它接受三个操作数，本质上是一个浓缩版的 `if-else`：

```
条件表达式 ? 表达式1 : 表达式2
```

条件为 `true` 时执行并返回表达式1，为 `false` 时执行并返回表达式2。

```cpp
int a = 10, b = 20;
int max = (a > b) ? a : b;     // max = 20

// 实用场景：小写字母转大写
char ch;
cin >> ch;
ch = (ch >= 'a' && ch <= 'z') ? (ch - 32) : ch;
cout << ch << endl;             // 输入 'a' → 输出 'A'
```

`'a' - 'A' = 32`（ASCII 码中小写字母比对应大写字母大 32），所以 `ch - 32` 把小写字母转成了大写。

三目运算符适合**简单的二选一赋值**；当条件逻辑变复杂时，应改用 `if-else` 以保证可读性。**嵌套三目运算符**（`a ? b ? c : d : e`）几乎所有编码规范都禁止使用。

### 运算符优先级

当多种运算符同时出现在一个表达式中时，优先级决定了计算的先后顺序（1 最高，15 最低）：

| 优先级 | 运算符 | 结合性 |
| :--- | :--- | :--- |
| 1 | `()` `[]` `.` `->` | 左到右 |
| 2 | `!` `~` `++` `--` `+`(正) `-`(负) `*`(解引用) `&`(取址) `sizeof` `(type)` | **右到左** |
| 3 | `*` `/` `%` | 左到右 |
| 4 | `+` `-` | 左到右 |
| 5 | `<<` `>>` | 左到右 |
| 6 | `<` `<=` `>` `>=` | 左到右 |
| 7 | `==` `!=` | 左到右 |
| 8 | `&`（按位与） | 左到右 |
| 9 | `^`（按位异或） | 左到右 |
| 10 | `\|`（按位或） | 左到右 |
| 11 | `&&` | 左到右 |
| 12 | `\|\|` | 左到右 |
| 13 | `?:`（三目） | **右到左** |
| 14 | `=` `+=` `-=` 等赋值 | **右到左** |
| 15 | `,`（逗号） | 左到右 |

> **实用建议**：这张表无需背下来。遇到不确定优先级的情况，**用 `()` 明确运算顺序**——它既能确保正确性，又能让读代码的人一眼看懂你的意图。`()` 优先级最高，可以把它当作"这里先算"的强调标记。

## 位运算

位运算直接对整数的二进制位进行操作，是 C++ 从 C 语言继承的最底层能力。它在日常业务代码里不常见，但在底层系统编程、竞赛、加解密、图形学、嵌入式开发中不可或缺——这也是 C++ 相对 Java、Python 的优势领域：它让程序员直接站在硬件层面思考问题。

### 原码、反码与补码

结论先给：现代计算机系统中，整数**一律用补码表示和存储**。以 32 位 `int` 为例，`-2` 的三种编码如下（只显示低 8 位）：

| 编码 | 二进制表示 | 说明 |
| :--- | :--- | :--- |
| **原码** | `1000 0010` | 最高位为符号位（1=负），其余为数值位 |
| **反码** | `1111 1101` | 符号位不变，其余位按位取反 |
| **补码** | `1111 1110` | 反码 + 1 |

**正数**的补码 = 反码 = 原码（三码合一）。**负数**的补码遵循三步：符号位保持为 1 → 其余位取反得反码 → 反码 + 1 得补码。

> **为什么用补码？** 如果直接用原码，`1 + (-1)` 的结果是 `0000 0001 + 1000 0001 = 1000 0010 = -2`（原码），完全错误。而用补码：`0000 0001 + 1111 1111 = (1) 0000 0000 = 0`（溢出的最高位丢弃），结果正确。补码让**加法器可以直接处理减法**——`a - b` 等价于 `a + (-b的补码)`，硬件设计大大简化。

### 位运算符

#### 六种位运算符

C++ 提供六种位运算符，按优先级从高到低排列：

| 运算符 | 名称 | 规则 | 示例（以 8 位为例） |
| :--- | :--- | :--- | :--- |
| `~` | 按位取反 | 0→1, 1→0（单目） | `~5` = `~00000101` = `11111010` |
| `<<` | 左移 | 低位补 0，高位丢弃 | `5 << 1` = `00001010` = 10（相当于 ×2） |
| `>>` | 右移 | 高位补符号位（有符号）或补 0（无符号） | `5 >> 1` = `00000010` = 2（相当于 ÷2） |
| `&` | 按位与 | 两位都为 1 结果才为 1 | `5 & 3` = `0101 & 0011` = `0001` = 1 |
| `^` | 按位异或 | 两位不同结果为 1 | `5 ^ 3` = `0101 ^ 0011` = `0110` = 6 |
| `\|` | 按位或 | 两位有一个为 1 结果即为 1 | `5 \| 3` = `0101 \| 0011` = `0111` = 7 |

它们的优先级顺序是 `~` > `<<` `>>` > `&` > `^` > `|`。下面这段程序把六种运算放在一起验证：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 3;          // a=0101, b=0011

    cout << (a & b) << endl;   // 0101 & 0011 = 0001 → 1
    cout << (a | b) << endl;   // 0101 | 0011 = 0111 → 7
    cout << (a ^ b) << endl;   // 0101 ^ 0011 = 0110 → 6
    cout << (~a) << endl;      // ~0000...0101 = 1111...1010 → -6（补码）
    cout << (a << 1) << endl;  // 5 * 2 = 10
    cout << (a >> 1) << endl;  // 5 / 2 = 2（整数除法截断）

    return 0;
}
```

#### 位赋值运算符

与算术赋值运算符类似，位运算也有对应的复合赋值形式：

| 运算符 | 示例 | 等价于 |
| :--- | :--- | :--- |
| `&=` | `a &= b` | `a = a & b` |
| `\|=` | `a \|= b` | `a = a \| b` |
| `^=` | `a ^= b` | `a = a ^ b` |
| `<<=` | `a <<= n` | `a = a << n` |
| `>>=` | `a >>= n` | `a = a >> n` |

位运算在具体问题上有一批常用套路，值得当作速查表记住：

| 场景 | 写法 | 说明 |
| :--- | :--- | :--- |
| 乘 2 的 n 次幂 | `x << n` | 比 `x * pow(2,n)` 快几十倍 |
| 除 2 的 n 次幂 | `x >> n` | 整数除法，向下截断 |
| 判断奇偶 | `x & 1` | 比 `x % 2` 更底层 |
| 取第 k 位 | `(x >> k) & 1` | 提取第 k 个二进制位的值 |
| 将第 k 位置 1 | `x \|= (1 << k)` | — |
| 将第 k 位置 0 | `x &= ~(1 << k)` | — |
| 大小写转换 | `ch ^= 32` | 因为 `'a' - 'A' = 32`（`0b100000`） |

> **例 3（用位运算判断奇偶与交换变量）** （1）用位运算判断一个整数是否为奇数；（2）不用临时变量，用异或交换两个整型变量的值。

**思路**：任何奇数的二进制最低位一定是 1（因为 $2^0=1$），所以 `num & 1` 可以提取最低位——结果为 1 是奇数，0 是偶数。异或满足交换律和结合律，且 `a ^ a = 0`、`a ^ 0 = a`、`a ^ b ^ b = a`，利用这三条性质就能原地交换两个数。

**解**：

```cpp
#include <iostream>
using namespace std;

int main() {
    // (1) 位运算判断奇偶
    int num = 7;
    if (num & 1) {
        cout << num << " 是奇数" << endl;
    } else {
        cout << num << " 是偶数" << endl;
    }

    // (2) 异或交换两数（无需临时变量）
    int a = 10, b = 20;
    a = a ^ b;    // a = 10 ^ 20
    b = a ^ b;    // b = (10 ^ 20) ^ 20 = 10 ^ 0 = 10
    a = a ^ b;    // a = (10 ^ 20) ^ 10 = 20 ^ 0 = 20
    cout << "a=" << a << ", b=" << b << endl;  // a=20, b=10

    return 0;
}
```

**评注**：位运算判断奇偶比 `num % 2` 更贴近硬件（现代编译器通常也会把 `% 2` 优化成同样的指令，但了解底层原理仍然有价值）。异或交换虽然巧妙，实际开发中却**不推荐**——它比引入临时变量更难理解，而且当 `a` 和 `b` 是同一个变量时会得到 `a = a ^ a = 0` 的错误结果。展示它主要是为了体会异或运算的性质，真正写代码时请老老实实用 `temp` 变量交换。

## 输入与输出

程序要和用户交互，就得接收键盘输入、把结果送出去。C++ 同时继承了两套 I/O 体系：来自 C 语言的 `scanf`/`printf` 和标准库的 `cin`/`cout`。两者的取舍很清楚——**`cin`/`cout` 类型安全、写起来省事；`scanf`/`printf` 格式控制精确、速度更快**。两套都要能读，同一段程序里保持风格一致即可。

### 输入语句

#### cin

`cin` 配合 `>>`（流提取运算符）使用，可以连续读取多个数据：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a;
    cin >> a;                     // 读取一个整数

    int x, y, z;
    cin >> x >> y >> z;           // 连续读取三个数（用空格或回车分隔）

    cout << "x=" << x << ", y=" << y << ", z=" << z << endl;
    return 0;
}
```

`cin >>` 在读取时**自动跳过前导空白字符**（空格、制表符、换行），遇到空白字符时停止读取。这意味着 `cin >>` 无法读取包含空格的字符串——它会在第一个空格处截断。

#### scanf

`scanf` 来自 C 语言的 `<cstdio>` 头文件，通过**格式控制符**精确指定读取的数据类型。它的最大优势是**效率高**——在数据量大的场合往往比 `cin` 快数倍：

```cpp
#include <cstdio>
using namespace std;

int main() {
    int a;
    scanf("%d", &a);                    // 注意：变量前必须加 & 取地址！

    int x, y, z;
    scanf("%d %d %d", &x, &y, &z);      // 连续读取三个整数

    printf("x=%d, y=%d, z=%d\n", x, y, z);
    return 0;
}
```

> **核心区别**：`scanf` 的变量参数前**必须加 `&`**（取地址符）——因为 `scanf` 需要知道变量在内存中的地址才能把读取的值写进去。忘记 `&` 是极常见的错误（编译器可能不报错，但运行时程序崩溃或行为异常）。`cin` 通过 C++ 的**引用**机制自动获取变量地址，所以不需要 `&`。唯一的例外是字符数组：`char str[10]` 的数组名本身就是首元素地址，`scanf("%s", str)` 不加 `&`。

`scanf` 的常用格式转换符：

| 格式符 | 对应类型 | 示例 |
| :--- | :--- | :--- |
| `%d` | `int` | `scanf("%d", &a);` |
| `%u` | `unsigned int` | `scanf("%u", &a);` |
| `%f` | `float` | `scanf("%f", &f);` |
| `%lf` | `double` | `scanf("%lf", &d);` ← 注意是 `lf` 不是 `f`！ |
| `%c` | `char` | `scanf("%c", &ch);` |
| `%s` | C 风格字符串（`char[]`） | `scanf("%s", str);` ← 数组名本身就是地址，无需 `&` |
| `%ld` | `long int` | `scanf("%ld", &l);` |
| `%lld` | `long long int` | `scanf("%lld", &ll);` |
| `%hd` | `short int` | `scanf("%hd", &s);` |

> **注意**：`double` 在 `scanf` 里用 `%lf`（long float），而 `float` 用 `%f`；但 `printf` 中 `float` 和 `double` **都用 `%f`**（因为 `float` 传参时会被自动提升为 `double`）。`scanf` 需要知道变量占几个字节才能正确写入，所以两者必须区分，`printf` 不需要。这个不一致是 C 语言历史遗留的最令人困惑的设计之一。

#### getline

`getline` 可以读取包含空格的一整行字符串，直到遇到终止字符（默认为换行 `'\n'`）：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);                  // 读取一整行（含空格）
    cout << "你输入了：" << s << endl;

    string s2;
    getline(cin, s2, ',');            // 读到逗号为止（逗号本身被丢弃）
    cout << "读到逗号前：" << s2 << endl;
    return 0;
}
```

> **注意**：`getline` 属于 C++ 标准库（`<string>` 头文件），读取的是 `string` 类型。它与 `cin >>` 混用时存在缓冲区陷阱——`cin >>` 读完数字后会在缓冲区里残留一个换行符，紧接着的 `getline` 会把那个换行符当作一个空行立即返回。解决办法是在两者之间插入一行 `cin.ignore()` 清掉残留的换行符。

#### getchar

`getchar` 从标准输入读取一个字符，返回其 ASCII 码：

```cpp
#include <cstdio>
using namespace std;

int main() {
    char c = getchar();       // 读取一个字符
    putchar(c);               // 输出该字符
    return 0;
}
```

`getchar()` 的返回类型是 `int` 而不是 `char`，这是为了能返回特殊的 `EOF`（通常为 -1）来表示输入结束；当没有更多输入时，`getchar()` 就返回 `EOF`。

四种输入方式的定位可以直接对照：

| 方式 | 来源 | 读取内容 | 特点 | 常见场景 |
| :--- | :--- | :--- | :--- | :--- |
| `cin >>` | C++ `<iostream>` | 以空白分隔的单词/数字 | 类型安全，使用简单 | 日常开发首选 |
| `scanf` | C `<cstdio>` | 按格式符精确读取 | **效率最高**，需手动 `&` 取址 | 数据量大、格式固定 |
| `getline` | C++ `<string>` | 一整行（含空格） | 只有它能读取含空格的字符串 | 读取姓名、地址等 |
| `getchar` | C `<cstdio>` | 单个字符 | 逐字符处理 | 逐字符解析输入 |

### 输出语句

#### cout

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, world" << endl;       // 输出并换行
    cout << "没有换行";
    cout << "继续在同一行" << endl;        // endl 表示换行并刷新缓冲区
    return 0;
}
```

`cout` 通过 `<<`（流插入运算符）链式调用，支持任意基本类型的直接输出，并且是类型安全的——编译器会自动根据数据类型选择正确的输出格式。

#### printf

```cpp
#include <cstdio>
#include <string>
using namespace std;

int main() {
    int a = 10;
    printf("a = %d\n", a);                // 输出：a = 10

    double pi = 3.14159;
    printf("pi = %.2f\n", pi);            // 输出：pi = 3.14（保留两位小数）

    // 输出 C++ 风格 string 需要 .c_str() 转换
    string s = "abcde";
    printf("s = %s\n", s.c_str());        // .c_str() 将 string 转为 C 风格字符串

    return 0;
}
```

> **关键差异**：`printf` 输出 C++ 的 `string` 类型时，必须调用 `.c_str()` 把它转成 C 风格字符串（`const char*`）。忘记 `.c_str()` 是常见错误——编译器可能不报错，但输出的是乱码。

#### puts 与 putchar

```cpp
#include <cstdio>
using namespace std;

int main() {
    puts("Hello, world");     // 输出字符串并自动换行
    putchar('A');             // 输出单个字符，不自动换行
    return 0;
}
```

`puts` 比 `printf("%s\n", str)` 简洁，但只能输出字符串且自动附加换行；`putchar` 只能输出单个字符，不做任何额外处理。

四种输出方式各有合适的位置：

| 方式 | 来源 | 特点 | 推荐场景 |
| :--- | :--- | :--- | :--- |
| `cout` | C++ `<iostream>` | 类型安全，可链式调用 | 日常开发首选 |
| `printf` | C `<cstdio>` | 格式控制精确，效率高 | 需要精细控制格式、大量输出 |
| `puts` | C `<cstdio>` | 简洁，自动换行 | 快速输出一行字符串 |
| `putchar` | C `<cstdio>` | 逐字符输出 | 逐字符处理 |

### 输出精度控制

#### cout 精度控制

用 `cout` 控制格式需要包含头文件 `<iomanip>`（input/output manipulators）：

| 操纵符 | 作用 | 示例 |
| :--- | :--- | :--- |
| `setprecision(n)` | 设置浮点数有效数字位数为 n | `cout << setprecision(3) << 12.34567;` → `12.3` |
| `fixed` | 强制使用小数表示法，与 `setprecision(n)` 连用表示保留 n 位小数 | `cout << fixed << setprecision(2) << 12.3;` → `12.30` |
| `showpoint` | 强制显示小数点及末尾的 0 | `cout << showpoint << 1.0;` → `1.00000` |
| `setw(width)` | 设置输出最小列宽（默认右对齐），配合 `left`/`right` 调整对齐方向 | `cout << setw(8) << 1.23;` → `    1.23` |

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double num = 12.34567;

    // 保留 3 位有效数字
    cout << setprecision(3) << num << endl;                    // 12.3

    // 固定小数点，保留 2 位小数
    cout << fixed << setprecision(2) << 232123434.357 << endl; // 232123434.36

    // 强制显示小数点后的 0
    cout << setprecision(6) << showpoint << 1.23 << endl;      // 1.23000

    // 控制列宽
    cout << right << setw(8) << 1.23 << endl;                  // "    1.23"
    cout << left  << setw(8) << 1.23 << "结束" << endl;        // "1.23    结束"

    return 0;
}
```

> **注意**：`setprecision`、`fixed`、`showpoint` 是**持续性**的——设置后对后续所有输出都生效，直到被重新设置；`setw` 是**一次性**的——只对紧随其后的一个输出项生效。

#### printf 精度控制

`printf` 的格式控制更简洁直观，格式为 `%[flag][width][.precision]specifier`：

```cpp
#include <cstdio>
using namespace std;

int main() {
    // 浮点数保留 n 位小数
    printf("%.3lf\n", 1.1234567);          // 输出：1.123

    // 整数位数限制（不足补 0）
    printf("%04d\n", 1);                   // 输出：0001

    // 最小列宽（右对齐）
    printf("%4d\n", 1);                    // 输出："   1"
    printf("%-4d 结束\n", 1);              // 输出："1   结束"（- 表示左对齐）

    // 综合使用
    printf("价格：%8.2f 元\n", 123.456);    // 输出："价格：  123.46 元"

    return 0;
}
```

| 格式控制 | 含义 | 示例 | 输出 |
| :--- | :--- | :--- | :--- |
| `%.nlf` | 保留 n 位小数 | `printf("%.2lf", 3.14159);` | `3.14` |
| `%0nd` | 宽度 n，不足补 0 | `printf("%04d", 1);` | `0001` |
| `%nd` | 宽度 n，右对齐 | `printf("%4d", 1);` | `   1` |
| `%-nd` | 宽度 n，左对齐 | `printf("%-4d", 1);` | `1   ` |
| `%m.nf` | 总宽度 m，小数 n 位 | `printf("%8.2f", 1.5);` | `    1.50` |

> **选择建议**：日常开发用 `cout`（类型安全），需要精细格式控制用 `printf`（简洁直观），大量输出时 `printf` 效率最高。同一个程序中尽量保持风格一致，不要 `cout` 和 `printf` 无规律混用。

> **例 4（格式化输出学生成绩单）** 输入学生的姓名、语文成绩、数学成绩、英语成绩（成绩为整数），输出格式化的成绩单。要求：姓名左对齐占 10 列，各科成绩右对齐占 6 列，平均分保留 1 位小数。

**思路**：姓名可能含空格，所以用 `getline` 读取；成绩用 `cin >>` 读取。输出列对齐用 `printf` 的格式控制最为方便——`%-10s` 左对齐姓名，`%6d` 右对齐成绩，`%.1f` 保留一位小数。平均分要注意整数运算陷阱：三个整数相加除以 `3` 会丢失小数，所以除数要写 `3.0` 强制浮点除法。

**解**：

```cpp
#include <iostream>
#include <string>
#include <cstdio>
using namespace std;

int main() {
    string name;
    int chinese, math, english;

    cout << "请输入姓名：";
    getline(cin, name);
    cout << "请输入语数英成绩（空格分隔）：";
    cin >> chinese >> math >> english;

    double avg = (chinese + math + english) / 3.0;   // 3.0 确保浮点除法

    // 输出表头
    printf("%-10s %6s %6s %6s %8s\n", "姓名", "语文", "数学", "英语", "平均分");
    printf("----------------------------------------\n");
    // 输出数据
    printf("%-10s %6d %6d %6d %8.1f\n", name.c_str(), chinese, math, english, avg);

    return 0;
}
```

程序输出（示例）：

```
请输入姓名：张三
请输入语数英成绩（空格分隔）：85 92 78
姓名         语文   数学   英语   平均分
----------------------------------------
张三          85     92     78     85.0
```

**评注**：这个例子把四个知识点串在了一起——`getline` 读取含空格的姓名、`cin >>` 连续读取成绩、`printf` 的格式控制负责列对齐与精度、`(a+b+c)/3.0` 强制浮点除法。注意输出 `name` 时调用了 `.c_str()`，这是 `printf` 输出 `string` 时的必备动作。也可以顺带体会一下：同样的格式，用 `printf` 写出来比 `cout << setw() << left << ...` 简洁得多，这正是 C 风格输出在格式化场景下依然被广泛使用的原因。

## 小结

1. 变量的值可以改、常量的值不能改，而 C++ **不会自动初始化局部变量**——声明时就赋初值是最省事的习惯。
2. 三种常量定义方式里，`const` 有类型、有作用域、调试可见，是日常首选；`enum` 用来给一组相关的整型常量起名字；`#define` 只在条件编译和头文件保护中保留价值。
3. 五类基本类型中 `int`（4 字节）与 `double`（8 字节）是默认选择，`float` 字面量必须加 `f` 后缀，`char` 存的是 1 字节的 ASCII 码。
4. 类型转换遵循"低精度向高精度看齐"；两个 `int` 相除会截断小数，`15 / 2` 得 `7`，想要小数必须让至少一个操作数是浮点数。
5. 运算符优先级可以用括号代替记忆，真正要防的是三类陷阱：`=` 与 `==` 混淆、自增自减写进复杂表达式、有符号与无符号混合运算。
6. 位运算直接操作二进制位，理解它的前提是整数在内存中以**补码**存储；判断奇偶用 `x & 1`，乘除 2 的幂用移位。
7. 两套 I/O 各有所长：`cin`/`cout` 类型安全，`scanf`/`printf` 格式控制精确且效率更高，读取含空格的整行只能用 `getline`。
