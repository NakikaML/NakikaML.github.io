  用法：
  1. 复制这个文件，改成你想要的文件名
     （文件名就是 URL，用英文小写 + 连字符最稳，例如 jvm-memory-model.md）
  2. 改上面的 frontmatter
  3. 直接在 `pnpm dev` 里预览：draft: true 只在开发服务器显示（带「草稿」徽章），
     构建时自动排除。写满意了再把 draft 改成 false —— 那一步才是「发布」
  4. 正文就正常写 Markdown

  frontmatter 字段说明（都可以留空，只有 title 必填）：
    title       标题（必填）
    description 摘要，显示在卡片上；不填会从正文自动截取
    category    分类，会出现在筛选按钮里，例如「计算机科学」「语言学习」
    date        日期，YYYY-MM-DD（这篇写给哪个时间点）
    updated     最后更新日期，YYYY-MM-DD。**只有回头改过这篇才填**，而且要
                比 date 晚，页面才会多出一行「已更新 · 更新于 X」——
                列表页的卡片也会从「日期」变成「↻ 更新于 X」，首页「最近更新」
                会把它排到前面。不填 = 没改过，页面跟以前一样干净。
                懒得手写日期就 `pnpm stamp <文件名>`（默认今天）。
    tags        标签数组
    difficulty  难度：基础 / 中等 / 困难
    draft       true = 草稿：只有 pnpm dev 里看得到，构建产物里没有
    featured    true = 在首页精选展示

  正文支持：Markdown 全语法、表格、代码高亮、LaTeX 公式、Mermaid 图。

  ⚠️ 写公式的一个提醒：多行公式请把 $$ 单独放一行，例如

        $$
        \begin{aligned}
        a &= b \\
        c &= d
        \end{aligned}
        $$

     不要写成 $$\begin{aligned} ...，那样 remark-math 会吞掉 \begin{...}，
