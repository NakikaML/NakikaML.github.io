## 树的直径

假设你被随机扔在树上的某个点，问"这棵树上最长的路在哪"：

> **从任意一点 $u$ 出发，走到离它最远的那个点 $A$；再从 $A$ 出发走到离它最远的 $B$ —— 则 $A$ 到 $B$ 就是一条直径。**

这是为什么呢？可以这么想：最长的路一定"穿过"了树的中心区域。如果你从 $u$ 出发往远处走，最先走到的"最远的尽头"必然是某条最长路径的一端 —— 否则你还能继续往外走，那条路就不是最长的了。

这就是**两次遍历求直径**：第一次找到端点 $A$，第二次找到另一个端点 $B$，长度就是 $B$ 到 $A$ 的距离。

### 直径求解代码

```cpp
const int N = 500005;
struct Edge { int to, w; };
vector<Edge> g[N];

long long dist[N];
int par[N], stk[N], n;

// 迭代 DFS：求 root 到所有点的距离，返回距离最远的点
int farthest(int root) {
    for (int i = 1; i <= n; i++) dist[i] = -1;
    dist[root] = 0;
    par[root] = 0;
    int sp = 0;
    stk[sp++] = root;
    int best = root;
    while (sp) {
        int u = stk[--sp];
        if (dist[u] > dist[best]) best = u;
        for (size_t i = 0; i < g[u].size(); i++) {
            int v = g[u][i].to;
            if (dist[v] == -1) {        // 树无环：第一次到达就是唯一路径
                dist[v] = dist[u] + g[u][i].w;
                par[v] = u;             // 记录父亲，便于还原路径
                stk[sp++] = v;
            }
        }
    }
    return best;
}

// 用法：
// int A = farthest(1);
// int B = farthest(A);   // 此时 dist[B] 就是直径长度，A→B 就是一条直径
```

想还原直径上的点，从 $B$ 顺着 `par` 往回走，走到 $A$ 为止，然后把序列反过来即可。

> **易错点**：`dist` 初始化为 `-1` 而不是 `0`。用 `0` 的话，边权为 0 的边会被误当成"访问过"，而且无法区分"没访问"和"距离是 0里"。

### 两次 DFS 失效的情况

**边权可以为负**的时候。两次 DFS 依赖"从任意点出发最远的点必是直径端点"，这条性质要求距离对深度单调 —— 负权边会让"越往下越远"不成立了。

好在竞赛里绝大多数题的边权是正的（长度、时间、权值），所以两次 DFS 是默认写法。真遇到负权，改用下面的树上 DP。

设 `down[u]` = 从 `u` 往下走的最长距离。把两条最优的"向下路径"在 `u` 处接起来，就是经过 `u` 的最长路径：

```cpp
long long down[N], ans = 0;

void treeDP(int u, int f) {
    down[u] = 0;                                    // 允许"一条边都不走"
    for (auto e : g[u]) {
        if (e.to == f) continue;
        treeDP(e.to, u);
        ans = max(ans, down[u] + down[e.to] + e.w);  // 在 u 处把两条向下路径拼起来
        down[u] = max(down[u], down[e.to] + e.w);
    }
}
```

`ans = max(ans, down[u] + down[v] + w)` ：先处理完所有儿子，再用"当前最优 + 这条新分支"去更新答案，最后把新分支并进 `down[u]`。注意 `down[u]` 是在循环里边算边用的 —— 所以"两条路径"一条来自已经处理过的儿子，一条来自当前儿子，天然不会重复走同一条边。

| 对比 | 两次 DFS | 树上 DP |
| :--- | :--- | :--- |
| 边权要求 | **非负** | 任意（含负权） |
| 复杂度 | $O(n)$ | $O(n)$ |
| 能否还原路径 | 能（顺着 `par` 回溯） | 能（记录取到最大值的儿子） |
| 代码量 | 极短 | 略长 |
| 什么时候用 | **默认** | 出现负权、或顺便要"每个点的向下最长路"时 |

### 树的直径的性质

| # | 性质 | 用途 |
| :--- | :--- | :--- |
| 1 | 任取点 $u$，距 $u$ 最远的点一定是某条直径的端点 | **两次 DFS 正确性的全部依据** |
| 2 | 固定一条直径 $(A,B)$，任意点 $v$ 到**最远点**的距离就是它与两个端点距离的较大者：$\mathrm{ecc}(v)=\max\{d(v,A),\,d(v,B)\}$ | 求所有点的最远距离，只要两遍遍历 |
| 3 | 所有直径必有**公共点**，且所有直径的**中点重合**（可能在一条边内部），叫**树心** | 判断直径是否唯一、直径中点类构造 |
| 4 | 直径上一点 $d_i$（到 $A$ 的距离 $P_i$，直径长 $Q$），挂在上面的子树深度 $h_i \le \min\{P_i,\,Q-P_i\}$ | 树的直径核心不等式 |

## 树的重心

### 定义

**重心**是这样的点：**删掉它之后，剩下的每个连通块（也就是它的各棵子树）大小的最大值最小**。

等价判据：

> 以重心为根，**每一棵子树的大小都不超过 $n/2$**。

如果有一棵子树超过 $n/2$，那么往那个儿子走一步，"最大的那块"一定变小 —— 所以当前这个点不是最优的。反过来，所有子树都不超过 $n/2$ 时，已经不可能再往任何方向改善了。

常用结论：

- 重心**至多两个**（两个时必定相邻，且 $n$ 为偶数）；
- 求重心时若发现有两个点都满足判据，题目没说取哪个时任选一个。

### 求法

在已经求出 `fa` 与 `sz`（子树大小）的前提下，对每个点 $u$ 检查两件事：

- 父亲那一侧（也就是"`u` 外面"）有多少点？$n-\text{sz}[u]$；
- 每个儿子的子树多大？$\text{sz}[v]$。

取这两个的最大值，最小的那个点就是重心：

```cpp
int centroid(int n) {                  // 需要先算好 fa[] 和 sz[]
    int res = 0, best = n + 1;
    for (int u = 1; u <= n; u++) {
        int mx = n - sz[u];            // 父亲那一侧的连通块
        for (int v : g[u])
            if (v != fa[u]) mx = max(mx, sz[v]);
        if (mx < best) { best = mx; res = u; }
    }
    return res;
}
```

:::example 例 1 · 手算一次重心
一棵 7 个点的树，根为 1：`1-2`、`1-3`、`2-4`、`2-5`、`4-6`、`4-7`。

**解**：先算子树大小（按 1 为根）：

| 点 | 子树含的点 | `sz` |
| :--- | :--- | :--- |
| 6、7、3、5 | 自己 | 1 |
| 4 | 4, 6, 7 | 3 |
| 2 | 2, 4, 5, 6, 7 | 5 |
| 1 | 全部 | 7 |

现在逐个点算"删掉它之后最大那块"：

| 点 | 最大的连通块 | 结论 |
| :--- | :--- | :--- |
| 1 | 5（下面那一大坨） | $5 > 7/2$，不是 |
| 2 | $\max(7-5,\ 3,\ 1)=3$ | $3 \le 3.5$ ✓ |
| 4 | $\max(7-3,\ 1,\ 1)=4$ | $4 > 3.5$，不是 |
| 其余 | —— | 删掉叶子只会剩下 6，更差 |

所以唯一重心是 **2**。注意它正好在直径 `6-4-2-1-3` 上 —— 这就是开头说的"重心一定在直径上"。
:::

### 树的重心的性质

| # | 性质 | 用途 |
| :--- | :--- | :--- |
| 1 | 至多两个；两个时相邻且 $n$ 为偶数 | 求重心的边界处理 |
| 2 | 以它为根，所有子树 $\le n/2$ | 等价判据，最好用 |
| 3 | **所有点到它的距离之和最小** | "会议选址""仓库选址"类问题 |
| 4 | 重心一定在某条直径上 | 结合直径互相验证 |
| 5 | 两个重心 $u,v$ 时，删掉边 $(u,v)$ 两侧各 $n/2$ 个点 | 断边后求重心类题目 |

> **易错点**：性质 3（距离和最小）只对**每个点权重都是 1** 的树成立。如果题目说"每个城市人口不同"，那是**带权重心的**，要按权值找带权中位数，判据变成"最大权值和的连通块 ≤ 总权值的一半"。看到人口、货物量这类词要先警惕。

:::example 例 2 · 求"所有点到它的距离和"最小的点
给定一棵 $n$ 个点的无权树，求一个点，使所有点到它的距离之和最小，并输出这个和。

**思路**：性质 3 说答案就是重心。但"距离和"本身不是重心算法算出来的，所以要再跑一次遍历累加距离。

也可以换个角度想：把根从 $u$ 挪到相邻的儿子 $v$，$v$ 那一侧的 $\text{sz}[v]$ 个点各自近 1，其余 $n-\text{sz}[v]$ 个点各自远 1，所以距离和的变化量是
$$n - 2\,\text{sz}[v]$$
只要这个值是负的，往 $v$ 挪就更优 —— 这正是"子树超过 $n/2$ 就往那边走"的重心判据。所以**重心就是最小值点**，两个重心时二者相等。

**解**：求出重心后，从重心做一次 DFS 累加深度和即可，总复杂度 $O(n)$。
:::

## 小结

- 求**最长路径** → 边权非负就两次 DFS，出现负权才上树形 DP；
- 求**最平衡的点 / 到所有点距离和最小** → 重心，一次求 `sz` + 一次扫描；
- 两者结合时记住：**重心在直径上**，而且所有直径共享中点。

:::summary
1. 直径 = 两次 DFS（非负权）或树形 DP（任意权），都是 $O(n)$。
2. 直径四条性质里，性质 1 撑起两次 DFS、性质 4 撑起"树网的核"这类题。
3. 重心 = 最大子树最小的点，判据是"每棵子树 ≤ $n/2$"。
4. 重心让**距离和**最小，但这条只在点权都为 1 时成立。
:::
